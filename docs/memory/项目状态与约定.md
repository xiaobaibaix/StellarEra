## N 体与关卡初态

- `UniverseMap` 是三体：三颗都是 `BP_VoxelPlanet_C`，**没有独立恒星**（中心那颗 C 也是体素行星，质量大当恒星用）。2026-10-18 14:48 改标定后：C (0,0,0) MassSolar 100、速度 0；A (−5,0,0) 与 B (+5,0,0) 各 0.873237、速度 (0,±28.0993,0)；飞船 (−5,+0.086185,0) 质量 0（测试粒子）、速度 (20,28.0993,0)。28.0993 = 2π√(100/5)，是 A/B 绕 C 的圆速度。
- 飞船贴 A 表面 r=0.086185 AU（A 表面半径 0.075 AU），偏置 +Y，落在行星轨道面内；飞船速度 = A 的速度 + 绕 A 的贴面圆速度 (20,0,0)。
- 唯一量化判据：`飞船轨道半径 / 行星在最近距离处的 Hill 半径`，`R_Hill = r_min × (m_A/(3·m_C))^(1/3)`。m_C=100 时 Hill 系数：m_A=100 → 0.69336，m_A=0.873237 → 0.14278。
- 实测：m_A=100 圆速度 → 最近 3.3335 / R_Hill 2.3113 / 3.73% 稳；m_A=100 初速 20 → 1.2709 / 0.8813 / 9.78% 稳；m_A=0.873237 圆速度（现状）→ 5.0000 / 0.7139 / 12.07%，100 年绑住（±0.29%，不动点）；m_A=0.873237 初速 20 → 1.6962 / 0.2422 / 35.59%，100 年绑住（±5%）；m_A=0.873237 且 A 在 −4.1767、圆速度 → 0.9946 / 0.1419 / 61%，t=1.39 年逃逸。
- 危险是「把 m_A 降到 0.873237」带进来的，不是关卡原状态；唯一真出事的 61% 是「低质量 + A 在 −4.1767」，A 已挪到 −5.0。
- 选 0.873237 的理由：让飞船贴面圆速度 √(4π²·m_A/0.086185) 正好 = 20.0000 AU/年 = 66667 cm/s；m_A=100 时是 214.0 AU/年 = 713330 cm/s，是飞船 MaxSpeed 8000 的 89 倍（0.873237 只要 8.3 倍）。
- 共面（i=0°）已治：飞船原在 A+(0,0,+0.086185) 是极向的，i=90° 时 Kozai–Lidov 会泵偏心率、约 9 年穿进行星；14:48 挪到 A+(0,+0.086185,0)。
- 等质量共轨不散架：m=100 时 A–B 100 年最小 6.667（圆速度）/ 2.5419（初速 20），两半径之和才 0.15；共轨时 Gladman 的 Δa 判据退化（a1=a2 → Δa=0），看沿轨道真实间距。
- 排障按「Hill 比值 → 共面 → A-B 距离」；别用「行星俯冲了没有」当判据；量行星轨道别用「离原点距离」（C 也在动、系统有净动量），必须两点直接距离；改 m_A 前重算上表。
- `NBodySimulator.cpp` 中 `ComputeAccelerations` 上方阻尼注释称「dt 在 1e-7 年量级，k·dt 在 1e-3 量级，远小于上限 2」，按代码自身数字反推对不上：`k·dt_step = (1/60) / (0.01 × 1.81) ≈ 0.92`（每帧 1.81 步见 `CosmosSimulationSubsystem.cpp:395`；τ = `ASpaceshipPawn::DampingTime` = 0.01 s）。推导与 TimeScale 无关（k 里的 TimeScale 与 Δt_sim 约掉），调 TimeScale 救不了；未实测，两个来源至少一个错。
- 0.92 贴着显式欧拉阻尼的单调边界 1（稳定上限 2，超过 1 就逐帧翻符号），比注释声称的余量小三数量级 → 阻尼通道不能再做更强制动：任何 τ 明显小于 10 ms 都会让 k·dt > 2 发散。
- 更狠的减速只能走外力通道（`ExternalAcceleration`），收敛刻度必须是本帧满推力的速度增量 `A·Δt`（外力整帧恒定，固定刻度低帧率过冲、3 fps 发散）。动阻尼前先实测 BaseTimeStep 再定 τ。
