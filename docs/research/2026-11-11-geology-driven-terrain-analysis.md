## 1. 背景与目标

**现状**：矿物是随机放置的。`UPlanetGeologyDistribution` 的 4 种形态（囊状 / 片层 / 脉状 / 浸染）
由 `SamplePlanetGeologyPlacement` 按带权深度随机撒点，与地形没有因果关系。

**目标**：矿物分布由地形成因决定，例如硫磺只在火山附近、盐类只在干旱的封闭盆地。
地形按成因逐层生成（大陆 → 火山带 / 断裂带 → 气候与地貌 → …），每层生成时按本层规律把矿物叠进密度场，
所有层叠完才进入网格化与渲染。

**难点**不在矿物，而在「宏观地形改由板块驱动」：它牵动 Hydrology、Water、Atmosphere、Surface、
生物群系 cubemap 和体素存档。

## 2. 总体架构：层如何叠加

### 2.1 与插件的对应
VoxelFree 对每个体素返回密度（`GetValue`）和材质（`GetMaterial`），全部求完才网格化。
项目已经在叠加：球形基底 + 噪声地形 + 水文下切 + 地质外凸 / 颜色（`UVoxelPlanetGenerator` 的
`Context.Hydrology` / `Context.Geology`）。新方案是把它规范成有序的层。

插件只对要网格化的 chunk 按需求值，多线程、任意 LOD，不存整颗星的三维场。
所以每层的逐体素部分必须是「位置 → 值」的纯函数；语义上仍是「每个体素按顺序走完所有层再交给网格化」。

### 2.2 局部层与非局部层

| 类型 | 例子 | 处理方式 |
|---|---|---|
| 局部：只看当前位置 | 球形基底、大陆噪声、单个矿囊、地层分层 | 逐体素直接计算 |
| 非局部：要看别处或全局 | 火山带（两板块相对运动）、河流（上游）、雨影（上风的山）、砂金（上游有原生矿） | 先在球面上烘焙二维图，逐体素只查表 |

### 2.3 每层的统一结构

```
第 i 层 = [可选] 烘焙：读第 < i 层的产物 → 输出球面二维图（板块 ID、边界距离、降水…）
        + 密度贡献：逐体素，读烘焙图
        + 矿物 / 材质贡献：逐体素，读烘焙图
```

烘焙在加载时或编辑器里跑一次，现有水文烘焙（`PlanetHydrologyBake`，6 面 × 512）就是这个模式。
流水线的先后顺序体现在烘焙段：后层可以读前层的产物。

### 2.4 叠加运算
- **密度**：高度偏移用加法；堆积（火山锥）用并集；下切（河谷、断裂）用差集。
  顺序有意义，后层可以挖掉前层，与「先成矿、后被侵蚀出露」一致。
- **矿物**：作为属性挂在体素上，基本不改形状。叠加规则待定（§10），现状是各元素取 max。
- 全部层跑完后做**材质合成**（不算一层）：把岩性、矿物、线索写进体素材质（§6.3），再进入网格化。

### 2.5 性能约束
- 每层的逐体素部分必须便宜，以查表为主。
- 每层都要给出值域（`GetValueRangeImpl`），插件才能整块跳过无关 chunk。层数越多越依赖这一条。
- 可挖到任意深度后，内部体素的**材质**也必须求值，不能像密度那样按整块实心跳过（§7）。

### 2.6 液体约定（已定）
本方案只产出固体，不含任何流动物质：
- **岩浆、外核**：按固态不流动处理，只是一种岩性 / 材质（例如「熔融色」的固体），可以挖。
- **水**：完全不做，包括海、湖、河水、地下水、卤水，由单独的水系统设计负责。
  本方案只留下水造成的**固体结果**：河谷、干湖盆、冲积扇、砂矿、盐壳、泉华等地貌与沉积。
- 「海平面」只作为一个高程参考量（陆架、海岸类地貌按它定位），不生成水体。
- 现有 `UPlanetWaterComponent` 等水面实现不在本方案范围内，阶段 B 改地形时只需保证它能继续读新的高程。

### 3.1 分层规则
- **一个矿撒在它全部条件都已就绪的最早那一层。** 砂金要原生金（4）+ 水系（6）→ 撒在 6；
  盐要干旱（5）+ 封闭盆地（6）→ 撒在 6；金刚石要深部源区（1）+ 克拉通（2）+ 金伯利岩管（4）→ 撒在 4。
- **气候在岩浆之后、侵蚀之前**：雨影要读山脉（3），河谷与剥蚀要读降水（5）。
- **3A、3B 插在宏观地形之后、岩浆之前**：沉积盆地要读第 3 层的高程，矽卡岩（第 4 层）要读 3A 的石灰岩，
  岩脉走向要读 3B 的断层。用 3A / 3B 编号是为了不打乱其它各层已有的编号与引用。
- **板块（2）与高程（3）分开**：板块是拓扑，高程是几何，分开后能单独可视化、单独调参。
- **莫霍面由第 2 层产出，不归第 1 层**：它的起伏来自地壳厚度（陆厚、洋薄、山根深），
  而且因果是「地壳厚度决定地表高程」（地壳均衡），第 3 层据此推出宏观高程，噪声只做细节。

## 4. 贯穿各层的基础概念

### 4.1 矿 = 背景含量 × 富集倍数
每种元素在地壳里都有背景含量（克拉克值），只有被地质过程富集几十到几千倍的地方才是矿床。
分工：第 1 层给「这里平均有多少」，第 2–7 层的过程给「在哪里被富集」。

| 元素 | 上地壳背景 | 典型可采品位 | 富集倍数 |
|---|---|---|---|
| Fe | ~4% | 25–60% | ~10× |
| Al | ~8% | 铝土矿 Al₂O₃ 40–60% | ~3–4× |
| Cu | ~30 ppm | 0.3–1% | ~100–300× |
| Zn / Pb | ~70 / ~17 ppm | 3–10% | ~500–2000× |
| Ni | ~50 ppm | 0.5–2% | ~100–400× |
| Cr | ~90 ppm | Cr₂O₃ 30–50% | ~2000× |
| Sn / W | ~2 ppm | 0.2–1% | ~1000–5000× |
| Au | ~1.5 ppb | 1–5 g/t | ~1000–3000× |
| U | ~3 ppm | 0.1–1% | ~300–3000× |

富集倍数越大越稀有、越依赖特定过程，适合做「要找」的高价值矿；Fe、Al 适合做大面积的常见矿。

### 4.2 元素亲和性（Goldschmidt 分类）
- 亲石（K、Na、Al、U、Th、稀土）：富集在地壳，尤其陆壳。
- 亲铁（Ni、Co、铂族、Au）：绝大部分沉进地核，地壳里极贫。
- 亲铜（Cu、Zn、Pb、S、Ag）：跟硫走，富集在硫化物里。
- 亲气（N、惰性气体）：大气与挥发分。

由此得到规则：深度决定元素家族的背景含量，后层过程再按家族挑选富集；也天然给出「越深越值钱」（§7.3）。

### 4.3 风格化比例
真实地壳只占半径的 0.5–1%，项目是公里级星球（`AVoxelPlanetActor` 注释「本项目 1km 星球」），照搬只有几米厚，
第 2–7 层的内容塞不进去。需要一条**深度缩放规则**：各层引用的地球深度（如斑岩在 1–4 km）
一律按「地球陆壳 35 km ↔ 风格化地壳厚度」换算，规则只写一处、各层都读它。
初步建议：地壳 15–25% R，地幔到约 0.55 R，地核占内侧，原型里按可玩性调。
水平距离同理按半径比例，例如板块数取 6–15 块。

### 4.4 形态原语
七层里反复出现的形态归成 7 种，实现时做成共用构件：

| 原语 | 出现在 | 边界特征 | 对应现有分布形态 |
|---|---|---|---|
| 起伏界面 | 莫霍面、核幔边界、风化前锋 | 窄面（或扩散面）+ 低频起伏 | 无，需新增 |
| 渐变带 | 地壳内部、气候带、冲积扇分选 | 宽的平滑过渡 | 浸染 |
| 团块 | 侵入体、深部团块、透镜体 | 硬接触 | 囊状 |
| 线状带 | 造山带金、洋中脊硫化物、绿岩带 | 平行于某条边界 | 脉状 |
| 层状 | 条带状铁矿、煤、层状侵入体、蒸发岩层 | 规整水平面 | 片层 |
| 同心分带 | 斑岩蚀变晕、蒸发岩环 | 一圈套一圈 | 无，需新增 |
| 沿流程衰减 | 砂矿 | 沿水流方向变化 | 无，需新增 |

现有 4 种形态保留，但位置改由各层烘焙图决定，不再随机。

## 5. 逐层分析

每层同一模板：形状 → 边界与过渡 → 矿物 → 分布规律 → 建模方式 → 依赖。

### 5.1 第 1 层：球体与深部分层

**形状**（地球值）：

| 圈层 | 地球深度 | 占半径 | 成分 |
|---|---|---|---|
| 陆壳 / 洋壳 | 0–35（山下 70）/ 0–7 km | 0.5–1% / ~0.1% | 花岗质 → 辉长质 / 玄武岩 |
| 上地幔 | 至 410 km | ~6% | 橄榄岩（橄榄石 ~60%） |
| 过渡带 | 410–660 km | ~4% | 橄榄石高压相 |
| 下地幔 | 660–2890 km | ~35% | 布里奇曼石 + 铁方镁石 |
| 外核 | 2890–5150 km | ~35% | 液态 Fe-Ni + ~10% 轻元素（本方案按固态处理，§2.6） |
| 内核 | 5150–6371 km | ~19% | 固态 Fe-Ni |

**边界与过渡**：既不是规整球面，也不是无规则扩散，分三种形态：
- 成分边界（壳幔莫霍面、核幔边界）：**窄而清晰的面，但面本身在起伏**。莫霍面山下深、洋下浅，
  起伏可达界面深度的数倍（Airy 均衡：山根深度约为地表高程的 6–7 倍）。
- 地幔相变面（410 / 660 km）：近似球面，±10–20 km 缓慢起伏。
- 地壳内部：渐变、断续，可用噪声扰动的过渡带表现，允许交错。
- 另有**嵌在层里的团块**：地幔柱、俯冲板片残骸、核幔边界上方的巨型低速体（LLSVP）。

**矿物**：本层主要提供岩性背景。

| 圈层 | 背景岩性 | 本层直接出的矿 |
|---|---|---|
| 地壳 | 长石 ~50–60%、石英 ~12%、辉石 / 角闪石 / 云母 | 无（由第 2–7 层富集），只给 §4.1 的背景含量 |
| 上地幔 | 橄榄石、辉石、石榴石、尖晶石 | 豆荚状铬铁矿、铂族；金刚石源区（150–200 km、克拉通厚根下） |
| 过渡带 / 下地幔 | 高压硅酸盐 | 无可采矿，可做「异质」深部材料 |
| 地核 | Fe ~85%、Ni ~5% | 极高品位铁镍、亲铁贵金属，可做终极资源 |

**分布规律**：
1. 按深度给元素家族的背景含量（§4.2）。
2. 深部团块是第 4 层地幔柱 / 热点的来源，位置要对齐。
3. 金刚石源区只在本层记录，撒矿在第 4 层（金伯利岩管）。

**建模**：
- 界面 = `r_boundary(dir) = 基准半径 + 低频起伏`，逐体素比较 `|p|` 与它，代价很低。
- 过渡带 = `smoothstep` 宽度 + 噪声扰动位置；宽度小得到清晰面，宽度大加 domain warp 得到交错扩散。
- 团块 = 少量 SDF + 噪声，列表加包围盒剔除。
- 值域：chunk 的半径范围完全落在一层内时直接给常量岩性。

**依赖**：无；被第 2 层（地壳厚度）、第 4 层（地幔柱、金刚石源区）读取。

### 5.2 第 2 层：板块构造

**形状**：
- 板块是球面上大小不一的不规则多边形，面积大致呈幂律分布；小星球取 6–15 块。
- **板块 ≠ 大陆**：一块板块常同时带陆壳和洋壳，大陆作为板块内部的团块单独生成。
- 地壳厚度：洋壳 ~7 km 近乎均匀；陆壳平均 ~35 km，造山带下到 70 km，裂谷和陆缘减薄到 20–30 km。
- 地壳年龄：洋壳在洋中脊最年轻、向两侧对称变老成条带；大陆中心是古老克拉通（> 25 亿年），外围是一圈圈更年轻的增生带。

**边界与过渡**：
- 洋壳边界是窄线（洋中脊、转换断层只有几 km 宽）；陆壳碰撞是宽带（可宽达上千 km）。宽度由地壳类型决定。
- 被动陆缘在 100–300 km 内渐变：陆架 → 陆坡 → 陆隆 → 深海平原。
- 边界类型由两侧相对速度定：法向分量为负是汇聚、为正是离散、以切向为主是转换；汇聚再分洋-洋 / 洋-陆 / 陆-陆。

**矿物**：

| 矿床 | 位置 | 形态 | 品位 / 规模 |
|---|---|---|---|
| 条带状铁矿（BIF） | 足够老的克拉通 | 层状，延伸几十到几百 km | Fe 25–35%，常见矿 |
| 绿岩带金 | 克拉通内的线状绿岩带 | 剪切带石英脉 | Au 数 g/t |
| 科马提岩镍 | 绿岩带底部 | 透镜体 | Ni 1–3% |
| 块状硫化物 | 洋中脊沿线 | 成串的离散透镜体 | Cu 1–3%、Zn 数 % |
| 锰结核 | 远离大陆的古老深海平原 | 海底面状散布 | Mn ~25%，伴生 Ni、Co、Cu |

**分布规律**：
1. 古老矿种只出现在年龄超过阈值的克拉通，大陆越老越富。
2. 洋中脊硫化物沿脊线成串，彼此有间隔。
3. 锰结核面密度 ∝ 洋壳年龄 × 离大陆距离。

**建模**（全部烘焙成 cubemap）：
- Fibonacci 球面点加抖动 → 球面 Voronoi → domain warp 让边界弯曲。
- 每块板块随机欧拉极和角速度，点速度 = ω × p；只取静态快照，不模拟演化。
- 大陆、克拉通是板块内的噪声团块。
- 产出：板块 ID、地壳类型、地壳厚度、边界类型、到边界测地距离、地壳年龄。

**依赖**：读第 1 层；被第 3、4、6 层读取。

### 5.3 第 3 层：宏观地形

**形状**：
- 大尺度高程由地壳均衡决定，地壳越厚越高。地球高程双峰：大陆约 +0.8 km，洋底约 −4 km。
- 洋底随年龄按 √年龄 变深：洋中脊约 −2.5 km，老洋底约 −6 km。
- 每种边界有固定剖面（离边界距离 → 高程）：

| 边界 | 剖面 |
|---|---|
| 洋-陆俯冲 | 海沟（宽 ~100 km）→ 弧前 → 离海沟 100–300 km 的火山弧山脉 → 弧后 |
| 洋-洋俯冲 | 海沟 + 岛弧 |
| 陆-陆碰撞 | 高耸主山脉 + 宽阔高原，山前有前陆盆地 |
| 洋中脊 | 比两侧高 2–3 km 的长脊，慢速脊顶有裂谷 |
| 大陆裂谷 | 地堑谷，两侧抬升的肩部 |
| 转换断层 | 线状谷地、地形错断 |
| 被动陆缘 | 陆架（0–200 m）→ 陆坡 → 深海平原 |

- 大陆内部：古老地盾低平；老造山带剥蚀成缓丘；年轻造山带高而陡。

**边界与过渡**：剖面光滑渐变，只有海沟和山脊线锐利。大尺度轮廓规则，「乱」来自细节噪声。

**矿物**：

| 矿床 | 位置 | 形态 | 品位 |
|---|---|---|---|
| 造山型金 | 平行于缝合线的剪切带 | 石英脉，延深可达数 km | Au 数 g/t |
| 蛇绿岩铬铁矿 | 缝合带上被推到陆上的洋壳和地幔碎片 | 豆荚状透镜体，零散成串 | Cr₂O₃ 30–50% |
| MVT 铅锌 | 前陆盆地边缘的碳酸盐地层 | 顺层分布 | Zn + Pb 5–10% |

**分布规律**：造山带的矿沿缝合线呈线状带，带宽由碰撞带宽度定；蛇绿岩只在曾关闭过大洋的缝合线上。

**建模**：
- 烘焙高程 cubemap：均衡基底（地壳厚度、洋壳年龄）+ 边界剖面（曲线资产或解析式）。
- 逐体素只叠细节噪声：山区 ridged + domain warp，平原低幅 fBm，幅度按区域类型调制。
- 替换现有 `UVoxelPlanetNoiseTerrain` 的纯 fBm 宏观形状；水文、水面、大气、生物群系都要改读它。

**依赖**：读第 2 层；被第 4–7 层读取。

### 5.4 第 4 层：岩浆活动

**形状**——地表火山（并集；火口、破火山口用差集）：

| 类型 | 位置 | 形状 |
|---|---|---|
| 层状火山 | 俯冲带火山弧 | 陡锥（~30°），顶有火口，沿弧成串，间距 50–100 km |
| 盾状火山 | 热点 | 缓坡（5–10°），沿板块运动方向成链，越远越老越矮 |
| 溢流玄武岩 | 大陆裂谷、大火成岩省 | 巨大平坦台地，内部层层叠起 |
| 破火山口 | 大喷发后塌陷 | 环形洼地（不积水） |
| 火山渣锥 | 火山群 | 成簇的小锥 |

地下侵入体（挖掘时会遇到）：

| 类型 | 形状 |
|---|---|
| 岩基 | 弧下方的巨大团块，宽数十到数百 km，顶面不规则穹状 |
| 岩株 | 岩基顶部伸出的小团块，宽 1–数 km，斑岩矿长在这里 |
| 岩墙 / 岩床 | 薄板：岩墙近垂直（放射状或平行成群），岩床近水平 |
| 层状侵入体 | 内部分出规整的水平层，全项目少有的「规整平面」 |
| 金伯利岩管 | 胡萝卜形竖直细管，直径数百 m |

**边界与过渡**：侵入体与围岩是**硬接触**，外面包着**同心蚀变晕**。斑岩系统从里到外：
钾化 → 绢英岩化 → 泥化 → 青磐岩化。形态是「团块 + 同心分带」，分带本身就是找矿线索。

**矿物**：

| 矿床 | 位置 | 形态 | 品位 / 规模 |
|---|---|---|---|
| 斑岩铜（钼、金） | 弧岩株顶部，深 1–4 km | 大型浸染体，宽 1–2 km | Cu 0.3–1%，规模巨大；岛弧偏 Cu-Au，陆弧偏 Cu-Mo |
| 浅成低温金银 | 斑岩上方 < 1 km | 脉状 | Au 数到数十 g/t |
| 硫磺 | 活火山顶、火口、喷气孔 | 地表结壳、充填 | 只在活火山；「活」只是点表属性，不做熔岩 |
| 矽卡岩（Cu、Fe、W、Zn） | 侵入体与石灰岩的接触带 | 沿接触面的不规则壳 | 需第 3A 层的石灰岩 |
| 锡钨 | 陆-陆碰撞带的花岗岩顶部 | 云英岩、石英脉 | Sn / W 0.2–1% |
| 伟晶岩锂、钽、铍 | 花岗岩边缘 | 透镜、脉 | 小而富 |
| 岩浆铜镍硫化物（铂族） | 镁铁质侵入体底部 | 底部团块和层 | Ni 1–3% |
| 层状侵入体铬、铂族 | 克拉通里的层状侵入体 | 很薄但横向连续 | 铂族数 g/t |
| 金伯利岩金刚石 | 古老克拉通 | 管状 | 每百吨几克拉，多数管子不含矿 |
| 碳酸岩稀土 | 大陆裂谷 | 小团块 | REO 数 % |

**分布规律**：
1. **弧岩浆系统是一根竖直矿柱**：地表硫磺 → 浅部金银 → 深部斑岩铜。这是最强的「地表线索 → 地下矿」机制。
2. 剥蚀改变出露：熄灭的老火山被削掉浅部金银，深部斑岩铜露出；剥蚀量来自第 6 层。
3. 热点链越老越矮，矿越少。
4. 金刚石要三条同时满足（第 1、2 层 + 本层管子），所以最稀有。

**建模**：
- 烘焙火山 / 侵入体点表（位置、类型、规模、年龄、是否活跃）：弧火山沿汇聚边界固定距离撒点，
  热点取第 1 层地幔柱位置，裂谷火山沿离散的陆壳边界撒点。
- 逐体素：火山锥 SDF 并集、火口差集；侵入体用地下 SDF 团块；蚀变带 = 到侵入体的距离分段；矿体放在侵入体顶部的固定相对深度。
- 每个火山、侵入体带包围盒，chunk 先按包围盒剔除。

**依赖**：读第 1–3 层；被第 6 层（砂矿源头、剥蚀）、第 7 层（表生富集）读取。

### 5.5 第 5 层：气候

**形状**（不改地形，只产出场）：
- 温度 = 纬度基础值 − 高程 × 直减率（~6.5 °C/km）± 大陆度。
- 盛行风：0–30° 信风（偏东），30–60° 西风，60° 以上极地东风。
- 降水纬度带：赤道多雨、30° 附近干旱（大沙漠所在）、中纬湿润、两极干冷；再叠山脉雨影与离海距离两项修正。
- 生物群系 = 温度 × 降水查表（Whittaker 图）：沙漠、草原、稀树草原、雨林、温带林、针叶林、苔原、冰原。

**边界与过渡**：大多是宽数百 km 的渐变带；只有山脊（雨影两侧可一边雨林一边沙漠）和海岸线锐利。

**矿物**：不撒矿，只给第 6、7 层提供干旱、湿热、寒冷等条件。

**建模**：
- 低分辨率 cubemap（256–512），气候是低频场。
- 雨影：从每点沿逆风方向回溯，每翻过一段抬升就扣掉一部分水汽。
- 现有 `PlanetBiomeCubemap` 只按高度和纬度分带（`PolarStart`、`SandToGrassHeight`），要改为读本层。
- 自转轴倾角、自转方向影响风带，按星球可配。

**依赖**：读第 3 层；被第 6、7 层读取。

### 5.6 第 6 层：侵蚀与沉积

本层只做水留下的**固体结果**，不生成水体（§2.6）。汇流量仍要算，但只作为决定河谷、砂矿、剥蚀的场。

**形状**：
- 河谷网呈树状，每条谷有自己的流域；山区 V 形谷，寒区 U 形冰川谷，低地河漫滩与曲流（都是干的地貌）。
- 山前冲积扇、河口三角洲；洼地是干湖盆；内流盆地在干旱区是盐滩。
- 剥蚀：山越高、越老、雨越多，削得越多，并把深部岩石和矿暴露出来。

**边界与过渡**：河道锐利；冲积扇和河漫滩渐变，按粒度分选（扇顶粗扇缘细、上游粗下游细）。

**矿物**：

| 矿床 | 条件 | 形态 / 位置 | 品位 |
|---|---|---|---|
| 砂金、砂锡、砂铂、砂金刚石 | 上游有原生矿（第 4 层）+ 水系 | 水流变缓处：曲流凸岸、急流下方、冲积扇、贴基岩的古河道底 | Au 0.1–1 g/t 即可采 |
| 滨海重砂（钛铁矿、锆石、金红石） | 河流把碎屑带到海岸 | 沿海滩条带 | 重矿物数 % |
| 蒸发岩 | 内流盆地 + 干旱（第 5 层） | 同心分带：边缘到中心依次碳酸盐 → 石膏 → 岩盐 → 钾盐 | 岩盐层可厚数百 m |
| 锂盐 | 干旱高原内流盆地 + 附近有火山（第 4 层） | 盆地中心的固态锂盐层（真实世界是卤水，本方案按固体） | Li 数百到上千 ppm |
| 煤 | 湿润（第 5 层）+ 低平三角洲或沼泽 | 水平薄层，层层叠起 | 层厚 1–10 m |

**分布规律**：
1. 砂矿必须有上游源头，品位沿流向衰减，在水流变缓处跳升。
2. 蒸发岩是同心环，规整好读。
3. 地表露出什么 = 原始深度 − 剥蚀量。

**建模**：
- 复用 `PlanetHydrologyBake`（汇流量、下切），改读第 3 层高程和第 5 层降水。
- 新增：内流盆地判定、沿流路传播并衰减的砂矿品位、剥蚀深度场。
- 逐体素：河谷湖盆差集；砂矿是贴谷底的薄层；蒸发岩按到盆地中心的距离分环。

**依赖**：读第 3–5 层；被第 7 层读取。

### 5.7 第 7 层：表生风化与特色地貌

**形状**：
- 风化壳：贴地表、随地形起伏的覆盖层。湿热雨林可厚数十 m，沙漠和陡坡几乎为零。
  红土剖面从上到下：铁质硬壳 → 斑杂带 → 腐岩 → 新鲜基岩。
- 特色地貌：沙丘（新月形、线形，走向随风）；喀斯特（石灰岩 + 湿润：漏斗、峰林、溶洞）；冰川地貌（冰斗、U 形谷、冰碛）；风化平原上的孤峰。

**边界与过渡**：风化前锋是**不规则的扩散面**，基岩以球状「核石」残留在风化层里；土壤分层渐变。
这是七层中最接近「无规则相互扩散」的边界。

**矿物**：

| 矿床 | 条件 | 形态 | 品位 |
|---|---|---|---|
| 红土型铝土矿 | 湿热 + 排水好的平缓台地 + 富铝母岩 | 近地表毯状层，厚 2–10 m 以上 | Al₂O₃ 40–60% |
| 红土型镍 | 湿热 + 超镁铁母岩（第 3 层蛇绿岩） | 毯状层 | Ni 1–2% |
| 次生富集铜 | 斑岩铜（第 4 层）上方、潜水面附近（不模拟地下水，按固定深度近似） | 淋滤帽下的富集毯 | 比原生矿高数倍 |
| 铁帽 | 硫化物矿体露头的风化残留 | 地表红褐斑块 | 本身价值低，是找矿线索 |
| 高岭土 | 花岗岩风化 | 风化壳中 | 工业黏土 |

**分布规律**：风化矿都要「母岩 × 气候」同时满足；本层产出最多的地表线索（铁帽、红土色、蚀变色）。

**建模**：
- 烘焙风化深度场（二维）：读第 5 层气候、第 3 层坡度、暴露时间。
- 逐体素：离地表深度小于风化深度的部分改成风化产物，前锋加噪声模拟核石。
- 地貌是地表高度的修饰：沙丘用沿风向的周期噪声，喀斯特漏斗用点 SDF 差集；比体素小的特征做不出来。

**依赖**：读第 3–6 层。

## 6. 找矿线索（核心玩法，已定）

真实找矿就是读线索：先看地形和岩石颜色，再取样、上仪器，最后才钻探。
线索全部从生成矿的同一套场派生，天然与地下一致，不需要手摆。**线索一律表现在材质上**，不依赖粒子与植被系统。

### 6.1 四个距离档

| 档 | 玩家在哪 | 线索 | 来源层 |
|---|---|---|---|
| 远观 | 飞船、轨道 | 火山锥与破火山口、白色盐滩、古老平坦地盾、成串山脉、红色台地 | 3、4、6、7 |
| 近看 | 落地步行 | 铁帽（红褐）、蚀变（漂白黄白、青磐岩化绿）、硫磺（亮黄）、红土、干河谷底的金色重砂、喷气孔与泉华（硫磺结壳 + 白色泉华材质，无水） | 4、6、7 |
| 仪器 | 用工具 | 磁力、重力、元素扫描；探测深度和精度有上限；以烘焙二维图投影到地表显示 | 全部 |
| 挖掘中 | 地下 | 蚀变晕逐圈变色、黄铁矿晕、侵入体接触面 | 4 |

### 6.2 线索对照

| 地表看到的 | 往下可能有 |
|---|---|
| 硫磺、喷气孔、彩色蚀变岩 | 浅成金银，再往深是斑岩铜 |
| 铁帽 | 硫化物矿体 |
| 盐滩 | 中心是钾盐、锂盐层 |
| 干河谷底的金色重砂 | 上游有原生金 |
| 红土台地 | 铝土矿；母岩是超镁铁岩时为红土镍 |
| 古老平坦地盾 | 条带状铁矿、绿岩金、金伯利岩管 |

### 6.3 两段典型流程
- **火山弧找金铜**：飞过火山弧看到黄白色斑块 → 落地发现硫磺和喷气孔 → 往下挖，岩石先漂白再变色 →
  浅处挖到金银脉 → 继续往深出现钾化色 → 斑岩铜矿体。
- **顺河谷找金源**：在干河谷底挖到金砂 → 沿河谷往上游逐段取样，金砂越来越多 → 某段突然没有了 → 原生金脉在这段两侧的山里。

### 6.4 材质承载（已核对插件源码）

插件容量：
- `FVoxelMaterial` 默认 8 个 8 位通道 `R G B A U0 V0 U1 V1`（`VoxelDefinitions.h` 的 `VOXEL_MATERIAL_ENABLE_*`）。
  `UV2`/`UV3` 默认关，开关在插件目录的 `VoxelUserDefinitions.h`，按「插件勿改」不动。
- 三种配置（`EVoxelMaterialConfig`）：
  - `RGB`：通道原样作为顶点色与 UV 传给材质，布局由项目自定。**现状只存了颜色。**
  - `SingleIndex`：只用 `A` 作索引（256 种），无混合。
  - `MultiIndex`：`R G B` 为 3 个混合权重、`A` 为湿度、`U0 V0 U1 V1` 为 4 个索引；插件负责三角形内的正确混合。

候选通道布局（RGB 配置，待原型验证）：

| 通道 | 含义 | 来源层 |
|---|---|---|
| R | 岩性索引（地壳各岩类、地幔、地核、风化产物） | 1、2、4、7 |
| G | 主矿物索引 | 各层 |
| B | 品位 0–255 | 各层 |
| A | 线索类型（高 4 位）+ 强度（低 4 位）：蚀变分带、铁帽、硫磺、盐壳、红土 | 4、6、7 |
| U0 / V0 | 共生次要矿物 + 品位 | 4 |
| U1 / V1 | 预留：生物群系、湿度、仪器标记 | 5 |

### 6.5 风险与限制
- **索引被插值**：顶点属性在三角形内线性插值，两种岩性相邻处会插出第三种。需在 shader 里取最近值，或改用 `MultiIndex`。**原型第一件要验证的事。**
- **只有网格表面可见**：地表线索和挖开的剖面都在表面上，没问题；但做不了「透视地下」，仪器档只能投影烘焙的二维图。
- **远观受 LOD 限制**：远处体素粗，小线索被平均掉。远观线索只放大尺度特征，细节在 shader 里读第 5–7 层 cubemap 补（现有生物群系 cubemap 同路）。
- **线索可靠度是难度旋钮**：多数金伯利岩管不含金刚石，「看到线索」≠「一定有矿」。
- **现有矿物透视与本玩法冲突**：X 光直接显示全部矿，玩家就不用找了（处置待定，见 §10）。

## 7. 「任何地方、任何深度都能挖」的影响

### 7.1 内部不能是均匀实心
- 挖开处处都露材质，**每个体素从地表到球心都要有岩性**。第 1 层从背景升级为完整内容：莫霍面起伏、地幔岩性、地核都要可见。
- 第 1、4 层的深部结构（岩基、层状侵入体、金伯利岩管）要做完整三维形状。
- 所有矿体都是三维实体，向下延伸要写清：脉延深多少、风化壳多厚、砂矿贴谷底多薄。

### 7.2 风格化比例
见 §4.3，必须在其它数值之前先定。

### 7.3 深度递进的回报
亲铁元素随深度升高，正好做成「越深越值钱」：地壳出常见矿和高价值脉矿，上地幔出铬、铂族、金刚石源区，
地核出极高品位铁镍与亲铁贵金属。越深代价越高（挖掘速度、温度或工具等级），属于玩法设计，待定。

### 7.4 对实现的连带要求
- 材质容量更关键：地表以下处处要存「岩性 + 矿物」（§6.4）。
- 内部材质求值不能跳过，第 1 层径向查表必须很便宜（§2.5）。
- 存档只存相对生成器的差量，任何深度挖过的地方在生成器改动后都对不上，影响面比只挖地表更大。
- 深隧道、竖井要有可靠碰撞；已知坑「碰撞细分路径锁死 Height 0」要在深部场景复测。
- 处处能挖意味着盲挖代价是玩家主要成本，线索决定先往哪挖，更说明 §6 必须做。

| 阶段 | 内容 | 回归面 | 体素存档 |
|---|---|---|---|
| 0 原型 | 材质通道布局 + 索引插值验证（§6.5 第一条） | 只有材质 | 不变 |

## 9. 所需知识

**优先级 1（定骨架）**：板块边界分类；成矿环境对照；VoxelFree 材质容量（已查清，§6.4）。

**优先级 2（实现骨架）**：
- 球面计算：Fibonacci 球面点、球面 Voronoi、测地距离场；cubemap 参数化、接缝、双线性采样。
- 噪声塑形：fBm、ridged、domain warp；「距离场 → 剖面」定宏观形状。
- 隐式建模：并集、差集、smooth min；**值域（区间）估计**，每层都要给 chunk 级上下界。
- 烘焙流水线：显式依赖、不可变共享结果（`TSharedPtr<const>`）、按层派生种子保证确定性、改一层只重烘其下游（扩展现有 Revision）。
- VoxelFree：生成器三个接口的调用时机与线程模型、LOD 的采样含义；存档差量与 `StoreSpecialValueForGeneratorValuesInSaves` 两种格式。

**优先级 3（阶段 C 才用）**：简化气候（三圈环流、雨影、Köppen）；风化、砂矿搬运、蒸发岩分带；特色地貌。

**工程与验证**：
- 每层一个 Instanced 子对象或 DataAsset，沿用 `UPlanetGeologyDistribution` 的多态写法；规则表用 DataAsset / DataTable。
- 每张中间图都能在编辑器里叠到球面上看，否则调不了参。
- 测试：确定性、值域保守性（估窄会出洞）、规则（火山弧外不出硫磺）。
- 性能：Insights 量逐体素耗时；烘焙耗时计入加载预算；编辑器前台测。

**候选资料**（未核实）：USGS 矿床模型（Cox & Singer 1986）、矿床学教材构造-成矿章节、Cortial 等 2019 *Procedural Tectonic Planets*。

## 11. 系统框架（不受现有代码结构约束）

### 11.1 两段式：烘焙期 + 求值期

```
星球配方 FPlanetRecipe（种子、半径、风格化比例、各层参数、矿床规则表）
        │
        ▼  烘焙期：每颗星跑一次，后台线程，可增量
┌──────────────────────────────────────────────┐
│ 层调度器：按声明的读写关系拓扑排序，逐层执行      │
│   层 i：Bake(读黑板) → 写球面场 / 基元集          │
│        → 本层的矿床规则：读黑板条件 → 产出矿体基元 │
│ 黑板 FGeoBlackboard：球面场 + 基元集 + 标量       │
└──────────────────────────────────────────────┘
        │  冻结（不可变、可跨线程共享）
        ▼
地质模型 FPlanetGeoModel（只读）
        │  求值期：按需、多线程、任意 LOD
        ├─► 体素适配器：GetValue / GetMaterial / GetValueRange
        ├─► 找矿查询：仪器扫描、取样、矿量统计
        ├─► 调试可视化：任意中间场叠到球面
        └─► 渲染辅助：远观线索 cubemap 交给 shader
```

核心原则：**层不知道体素插件，体素插件不知道层。**中间只隔一个只读的地质模型。
玩法、渲染、矿物视图、测试都查同一个模型，保证「看到的线索」和「挖到的矿」永远一致。

### 11.2 三种数据形态

| 形态 | 类型 | 存什么 | 求值方式 |
|---|---|---|---|
| 球面场 | `TSphereField<T>`（cubemap，6 面 × N²，带接缝处理与双线性采样） | 板块 ID、地壳厚度、边界距离、高程、降水、剥蚀深度、风化深度… | 按方向查表 |
| 基元集 | `FGeoPrimitiveSet`（基元数组 + BVH） | 火山、侵入体、矿体、深部团块 | 按位置查 BVH，再逐个求 SDF |
| 径向剖面 | `FRadialProfile` | 圈层界面基准半径、背景岩性、元素背景含量 | 按半径查表，叠加界面起伏场 |

黑板按**强类型键**存取（`FGeoFieldKey<float> CrustThickness` 一类），层声明读哪些键、写哪些键，调度器据此排序并检查「读了没人写的键」。

### 11.3 层接口

```cpp
class IGeoLayer
{
    virtual FName GetName() const;
    virtual void DeclareIO(FGeoLayerIO& IO) const;          // 读写哪些键
    virtual void Bake(const FGeoBakeContext& Ctx, FGeoBlackboard& Board) const;
    // 求值期贡献（可选；纯条件层如气候没有这一项）
    virtual TSharedPtr<const IGeoContributor> CreateContributor(const FGeoBlackboard& Board) const;
};

class IGeoContributor   // 冻结后的只读求值器，线程安全
{
    virtual void ApplyDensity (const FGeoPoint& P, float& InOutDensity) const;   // 加 / 并 / 差
    virtual void ApplyMaterial(const FGeoPoint& P, FGeoSample& InOut) const;     // 岩性、线索
    virtual FGeoRange GetRange(const FGeoBox& Box) const;                        // 值域，整块剔除用
};
```

`FGeoPoint` 预先算好方向、半径、风格化深度，各层不重复算。贡献器按层号顺序叠加，顺序即 §2.4 的叠加语义。

### 11.4 矿床规则：数据驱动

「撒矿」不写死在层的代码里，而是一张规则表，每条规则挂在某一层之后执行（§3.1：条件全部就绪的最早一层）。

```
规则 = 条件 + 放置 + 形态 + 品位
  条件：对黑板的谓词组合，例如 边界类型==洋陆俯冲 且 到海沟距离∈[a,b] 且 火山.活跃
  放置：在哪生成实例：沿线撒点 / 在基元附近 / 在场的阈值区域内 / 按面密度随机
  形态：§4.4 的 7 种形态原语之一 + 尺寸、延深、走向（走向可取自场，例如平行于缝合线）
  品位：峰值品位 × 剖面（中心→边缘、深度→衰减），共生矿物列表
  线索：本矿床在地表 / 围岩留下的线索类型与范围（蚀变晕、铁帽、盐壳…）
```

规则产出的是矿体**基元实例**，写进黑板的基元集；求值期统一由「矿床贡献器」查 BVH 求值。
所以规则只在烘焙期跑，求值期没有规则逻辑，代价只有查 BVH + 求 SDF。

### 11.5 形态原语库

§4.4 的 7 种原语做成共用构件，每种都实现同一组接口：`Evaluate(P) → 强度 ∈ [0,1]`、`GetBounds()`、`GetRange(Box)`。
层（火山锥、侵入体）与矿床规则（矿囊、矿脉）复用同一套原语，原语自带值域实现，剔除逻辑不用每处重写。

### 11.6 材质合成与编码

求值结果先落在语义结构上，最后一步才编码进体素材质：

```
FGeoSample { Density, Lithology, Mineral, Grade, SecondaryMineral, SecondaryGrade, Clue, ClueStrength }
        │  FGeoMaterialCodec（全项目唯一一份编码规则，§6.4 的通道布局）
        ▼
FVoxelMaterial
```

编解码只有一处：体素适配器编码，shader 与找矿查询解码。以后换 MultiIndex 或改通道布局只改这一个类。

### 11.7 求值期的适配器

| 适配器 | 职责 | 约束 |
|---|---|---|
| 体素生成器 | 把 `FGeoPoint` 换成体素坐标、调各贡献器、编码材质、汇总值域 | 很薄，不含地质逻辑 |
| 找矿查询 | 仪器扫描（按场投影到地表）、取样（单点 `FGeoSample`）、矿量统计 | 只读模型，不读体素数据，不随 LOD 变 |
| 调试可视化 | 任意黑板键 → 球面上的伪彩色叠加；基元集画包围盒 | 编辑器专用 |
| 线索 cubemap | 远观档的大尺度线索烘成贴图交给 shader | 解决远处 LOD 粗的问题（§6.5） |

### 11.8 确定性、缓存与存档

- **确定性**：每层种子 = Hash(星球种子, 层名)；规则种子 = Hash(层种子, 规则 Id)。同一配方必须烘出逐位相同的模型。
- **增量烘焙**：每层输出带内容哈希 = Hash(本层参数, 输入键的哈希)。改一层只重烘它和下游。
- **存档兼容**：模型整体哈希写进体素存档头。读档时哈希不符就明确报错或走迁移，而不是悄悄读出一颗坏星。

### 11.9 模块划分

| 模块 | 内容 | 依赖 |
|---|---|---|
| GeoCore | 黑板、调度器、球面场、基元集与 BVH、形态原语、层与贡献器接口、规则引擎 | 只依赖 UE Core，不依赖体素插件，可纯 C++ 单测 |
| GeoLayers | 7 层的具体实现 + 规则执行 | GeoCore |
| GeoAssets | 配方、层参数、规则表的 DataAsset，以及「资产 → 运行期配方」的转换 | GeoCore、CoreUObject |
| GeoVoxel | 体素生成器适配器、材质编解码 | GeoCore、Voxel |
| GeoTools（编辑器） | 调试可视化、烘焙统计、规则命中报告 | 以上全部 |

依赖单向：Core ← Layers / Assets ← Voxel / Tools。地质逻辑全部在不认识体素插件的模块里，可脱离引擎测试。

### 11.10 生命周期

1. **编辑**：改配方或规则 → 资产转成配方 → 增量烘焙（后台）→ 冻结新模型 → 原子替换 → 体素世界按变化区域刷新。
2. **加载**：读配方 → 烘焙（或读编辑器预烘的结果，§10「烘焙时机」）→ 冻结 → 创建体素世界。烘焙完成前不建世界。
3. **运行**：模型只读；挖掘只改体素数据（差量），不改模型。

### 11.11 框架层面的待定
- 烘焙耗时预算与球面场分辨率（气候 256、地形 512–1024 量级）。
- 基元总数上限与 BVH 形式。
- 规则表的表达形式：DataAsset 里的结构化条件，还是一个小型表达式语言。
- 增量烘焙是否值得做（取决于全量烘焙要多久）。

## 12. 缺口清单（2026-11-11 自查）

### 12.1 地学内容缺口（会让规则断链）
- **沉积盖层与地层没有归属层。** 矽卡岩、MVT 铅锌、喀斯特都要求「围岩是石灰岩」，煤要求沉积层序，
  但七层里没有一层产出「地表以下几百米是什么沉积岩、怎么叠」。需要补一层（或并入第 3 层）：
  按盆地 / 陆架 / 被动陆缘生成沉积层序（砂岩、页岩、石灰岩、蒸发岩），给出三维岩性。
- **变质作用缺失。** 造山带的区域变质（片岩、片麻岩、大理岩）既是岩性来源，也决定造山型金、石墨等矿的位置。
- **断层与褶皱只有二维。** 现在边界只是球面上的线；可挖到任意深度后，断层要是三维面（错断地层、控制脉的走向），褶皱要能把地层弯起来。
- **统一的地质时间轴。** 多处用到「年龄」（克拉通、洋壳、火山、剥蚀暴露时间），但没有一条全局时间定义，各层的年龄会互相矛盾。
- **非类地星球。** 卫星、小行星、无板块的星球需要不同的层组合，框架要允许「按星球类型选层集」。

### 12.2 数据定义缺口
- **岩性目录与矿物目录**：唯一注册表，含 Id、显示名、颜色 / 贴图、硬度、密度、对应的线索。目前文档只散列了名字。
- **元素 ↔ 矿物 ↔ 玩家资源的映射**：挖到「斑岩铜 0.5%」玩家拿到什么、多少。产出计算没有设计。
- **矿是否改形状**：现有 `SampleGeometryDelta` 让矿脉顶起地表；新方案里矿只作属性还是也改密度，未定。

### 12.3 玩法与平衡缺口
- **资源总量与分布目标**：每颗星每种矿应有多少、离出生点多远、多深，没有目标值，规则参数无从调起。
- **统计报告工具**：烘焙后自动出「各矿总量、出露比例、线索命中率」报告，用来做平衡；§11.7 只有可视化，没有统计。
- **仪器的具体规格**：替代现有矿物透视的仪器（范围、深度、精度、单元素），以及现有透视的去留（§10）。
- **挖掘手感**：按岩性硬度决定挖掘速度、工具等级，与 §7.3 的深度代价合在一起设计。

### 12.4 渲染缺口
- **shader 侧设计**：通道解码、岩性 → 贴图 / 颜色、三平面映射、索引插值的处理（§6.5 第一条）。
- **粗 LOD 的材质聚合**：远处一个体素代表很大体积，材质该取主导岩性、加权平均还是保留稀有矿的线索，没有定义。
  直接点采样会让远观线索闪烁或消失。

### 12.5 系统集成缺口
- **对外契约**：给水系统（海平面、河谷、盆地位置）、大气（最低地表半径）、地表射线、着陆、生物群系 / 天空的接口要列清；
  阶段 B 换地形时它们只依赖契约，不依赖层的内部实现。
- **迁移方案**：现有地质预设、矿物视图、`PlanetHydrologyBake`、已有体素存档如何过渡或废弃。
- **跨平台确定性**：浮点在不同 CPU / 编译选项下的差异会让「同种子同星球」失效，联机或分享种子时才会暴露，需先定是否要求。

> 以上缺口已在 §13 逐条给出补齐提案：12.1 → §13.1–13.4；12.2 → §13.5–13.7；12.3 → §13.8–13.10；12.4 → §13.11–13.12；12.5 → §13.13–13.15。

### 12.6 补齐顺序建议
1. 先补地学内容（12.1），否则规则表有断链。
2. 再定数据目录与产出映射（12.2），它们是规则表与平衡的前提。
3. 平衡目标与统计工具（12.3）在原型前定，渲染与集成（12.4、12.5）在阶段 0 / A 原型中验证。

## 13. 缺口补齐（提案，2026-11-11）

数值仍为地球常识量级、未核实；标「建议」的是待用户确认的设计选择。

### 13.1 第 3A 层：沉积盖层

**为什么要单列**：矽卡岩、层控铅锌、喀斯特要求石灰岩，煤要求沉积层序；可挖到任意深度后，
大陆上部几百米到几 km 的岩性主要就是沉积岩，没有这一层地下就是一整块花岗岩。

**形状**：
- 盖层厚度场（二维）：克拉通地盾裸露（≈0）；内陆盆地、前陆盆地、被动陆缘、陆架最厚（地球上可达 5–15 km）；造山带被剥蚀变薄。
- 层序（每处一根「地层柱」）：从下到上若干层，每层 = 岩性 + 厚度。岩性按沉积环境查表：

| 沉积环境（由第 3 层位置 + 第 5 层气候定） | 主要岩性 |
|---|---|
| 浅海陆架、温暖 | 石灰岩、白云岩 |
| 深海 | 页岩、燧石 |
| 三角洲、河流 | 砂岩、粉砂岩、页岩互层 |
| 湿润低地沼泽 | 页岩 + 煤层 |
| 干旱封闭盆地 | 红层砂岩、古蒸发岩（石膏、岩盐） |
| 山前 | 砾岩 |

- 古环境：每根地层柱由下到上代表从老到新，**下部层用「古环境」**（按时间轴 §13.3 让海平面与气候带随年代变化），
  这样同一处地下可以是「下石灰岩、中煤系、上红层」，也顺带解决了「古气候」待定项（煤可以出现在今天的沙漠底下）。

**边界与过渡**：层面近水平、彼此平行，是全方案最规整的界面；横向上岩性渐变（相变），层厚缓慢变化。
被 3B 的褶皱弯曲、被断层错开。

**矿物**：

| 矿床 | 位置 | 形态 |
|---|---|---|
| 层控铅锌（MVT，原第 3 层移来） | 盆地边缘石灰岩 / 白云岩层内 | 顺层透镜 |
| 煤 | 煤系层段 | 薄层，横向连续 |
| 古蒸发岩（岩盐、钾盐、石膏） | 干旱期层段 | 厚层，可形成盐丘（可选） |
| 砂岩型铀 | 河流相砂岩，靠近花岗岩源区 | 卷状透镜 |
| 沉积铁、锰 | 浅海层段 | 薄层 |

**建模**：烘焙「地层柱表」：球面上低分辨率网格（每格一根柱：层数 ≤ 8、每层岩性 + 厚度），柱间插值厚度。
逐体素：先用 3B 的变形把点换回「未变形的地层坐标」，再按深度查柱得到岩性。

**依赖**：读第 2、3、5 层与时间轴；被 3B、4、6、7 层读取。第 6 层的现代沉积（冲积扇、三角洲）是盖层最顶部的一层。

### 13.2 第 3B 层：构造变形与变质

**断层（三维）**：
- 每条断层 = 一张有界的面：地表迹线（来自第 2 层边界或板块内部撒的次级断裂）+ 倾角 + 向下延深 + 位移量与方向。
- 类型：正断层（裂谷，陡倾 60°）、逆冲断层（造山带，缓倾 20–30°，成叠瓦状）、走滑断层（转换边界，近直立）。
- 作用：断层两侧的地层按位移量错开；断层带本身是一条薄的破碎带（岩性「断层泥 / 角砾岩」）。
- 控矿：造山型金、热液脉沿断层面分布（原第 3 层的造山型金改由本层控制位置）。

**褶皱**：
- 造山带内平行于缝合线的波状褶皱，波长和幅度随离缝合线距离减小。
- 实现为坐标变形场：逐体素先把点沿「上」方向按 `A(d)·sin(k·s)` 偏移（s 为垂直于褶皱轴的坐标），再去查 3A 的地层柱。

**变质**：
- 变质等级场：造山带核部高（片麻岩、混合岩）→ 外侧中（片岩）→ 边缘低（板岩、千枚岩）；侵入体周围接触变质由第 4 层负责。
- 作用于岩性映射：同一原岩随等级换名，石灰岩→大理岩、页岩→板岩→片岩→片麻岩、砂岩→石英岩、煤→石墨。
- 矿：石墨、蓝晶石 / 石榴石等工业矿物（可选）。

**建模**：断层是基元集（面片 + 包围盒）；褶皱与变质是由第 2 层边界距离派生的场。
求值顺序：变形（断层位移 + 褶皱）→ 查地层 → 变质换名。值域：断层按包围盒剔除；褶皱只在造山带区域生效。

**依赖**：读第 2、3、3A 层；被第 4（岩脉走向）、6（断层谷）、7 层读取。

### 13.3 统一地质时间轴

- 一颗星一条时间轴：`t = 0`（星球形成）到 `t = T_now`，单位「地质纪」（风格化，不必等于百万年）。
- 每个产物带「形成年代」：克拉通、洋壳条带、地层、火山、侵入体、断层、风化壳。
- 时间轴上有少量**事件**（建议 3–6 个）：造山期、裂谷期、海进 / 海退、干旱期、湿润期。
  3A 的古环境、第 4 层火山年龄、第 6 层剥蚀暴露时间都从事件表读，不各自随机。
- 一致性规则：新的切老的（侵入体、断层、岩脉年龄必须晚于被切的地层），烘焙时校验，违反就报错。
- 不做真正的演化模拟，只是一张事件表 + 每个产物一个年龄标签。

### 13.4 星球类型与层集

| 星球类型 | 启用的层 | 差异 |
|---|---|---|
| 类地（有板块） | 全部 | 默认 |
| 停滞盖层（类火星） | 1、2（单板块）、3、3A、4（只有热点）、5、6、7 | 无俯冲带：无斑岩铜、无弧火山；巨型盾状火山 |
| 无大气卫星 / 小行星 | 1、3（陨石坑代替板块地形）、4（可选） | 无气候、无侵蚀、无风化；新增「撞击层」：陨石坑、溅射毯、撞击熔融体；矿以深部岩浆型和陨铁为主 |
| 冰卫星 | 方案外（依赖水 / 冰，另设计） | — |

框架上「层集」是配方的一部分：配方列出启用哪些层，调度器按读写关系检查缺失的上游（例如关了第 5 层却开了第 7 层就报错）。
撞击层是新层，建议放到阶段 C 之后。

### 13.5 岩性与矿物目录

两张唯一注册表（DataAsset），所有层、规则、材质编解码、shader、玩法都只认 Id：

**岩性目录** `FLithologyDef`：Id、显示名、大类（火成 / 沉积 / 变质 / 风化 / 深部）、颜色 + 贴图集、
硬度（1–10，决定挖掘速度）、密度（仪器重力扫描用）、磁性（磁力扫描用）、变质映射（低 / 中 / 高等级换成哪个 Id）、风化映射。

**矿物目录** `FMineralDef`：Id、显示名、颜色 + 贴图、所含元素及比例、硬度修正、
是否可见（有些矿肉眼看不出，只能靠仪器）、对应的线索类型。

**容量估计**：岩性约 30–50 种、矿物约 30–60 种，各自都在 8 位索引（256）之内，§6.4 的通道布局够用。

### 13.6 产出映射（挖到矿得到什么）

- 挖掉一个体素 → 读它的 `FGeoSample`（岩性、主矿物 + 品位、次要矿物 + 品位）。
- 产出 = 体素体积 × 岩性密度 × 品位 × 矿物的元素比例 → 按元素累加到玩家资源。
- 品位通道 0–255 按每种矿物自己的「品位上限」线性映射（金的上限是几十 g/t，铁是 60%），不共用一个刻度。
- 废石（品位低于边界品位）只产出岩性本身（建材类资源）或不产出，由玩法定。
- 建议：资源以**元素**为单位（Fe、Cu、Au…），矿物只是元素的载体；这样不同矿床给出同一种资源，平衡只调元素。

### 13.7 矿是否改形状（建议）

- 默认**不改**：矿只作为属性，地形形状只由层的密度贡献决定。
- 例外只在少数「抗风化凸起」上：石英脉、铁帽、硬质侵入体比围岩耐侵蚀，在地表留下小脊。
  这由第 6 层剥蚀按岩性硬度差决定，不由矿床规则直接改密度。
- 现有 `SampleGeometryDelta`（矿脉顶起地表）在新方案中删除。

### 13.8 资源平衡目标与统计报告

**目标值**（每颗星、每种元素，建议填进配方，原型里调）：
- 总储量（元素吨数量级）。
- 出露比例：地表可见 / 浅部（< 1 个风格化地壳厚度的 5%）/ 深部 的分布。
- 离出生点的距离分布：保证出生点附近有常见矿（Fe、Cu、建材），稀有矿（Au、金刚石、铂族）至少要走一段。
- 稀有度阶梯：常见（Fe、Al、建材）> 中等（Cu、Zn、Pb、Ni）> 稀有（Sn、W、U、Li）> 极稀有（Au、铂族、金刚石）> 深部专属（地核铁镍）。

**统计报告**（烘焙后自动生成，编辑器工具 GeoTools）：
- 每种元素：总量、按深度带的分布、按距离出生点的分布、各矿床类型的贡献。
- 线索命中率：有线索处真的有矿的比例（对应可靠度旋钮）、有矿处有线索的比例。
- 规则命中：每条规则实际产出了几个实例；产出 0 个的规则标红（多半是条件写错）。
- 与目标值的偏差，超出容差标红。
- 统计用找矿查询（§11.7）对模型采样，不读体素。

### 13.9 仪器规格与矿物透视的去留（建议）

| 仪器 | 读什么 | 范围 / 深度 | 显示 |
|---|---|---|---|
| 地质锤（取样） | 单点 `FGeoSample` | 手边 | 岩性名、可见矿物、粗略品位 |
| 磁力仪 | 岩性磁性的深度加权和 | 半径大、深度中 | 地表投影的等值线 / 伪彩色 |
| 重力仪 | 岩性密度异常的深度加权和 | 半径大、深度深 | 地表投影的伪彩色，分辨率低 |
| 元素扫描仪 | 指定一种元素的品位 | 半径小、深度浅 | 地表投影的热力图，只显示一种元素 |
| 钻探 | 一根竖直柱上的逐段 `FGeoSample` | 一个点、可到很深 | 岩芯剖面图 |

- 所有仪器都只读地质模型（§11.7 找矿查询），与体素和 LOD 无关。
- **现有矿物透视（X 光三维矿体）建议改为只留编辑器调试**；玩家侧由上表仪器替代，钻探岩芯是唯一能看到「地下竖直剖面」的方式。

### 13.10 挖掘手感（建议）

- 挖掘速度 = 工具功率 / 岩性硬度；硬度来自岩性目录。
- 深度代价：随风格化深度增加的「温度 / 压力」系数乘到硬度上；地幔、地核需要更高等级工具。
- 不同岩性给不同的挖掘反馈（颜色、声音、碎屑），这是近看档以外的另一种线索。

### 13.11 shader 侧

- **解码**：材质函数 `MF_GeoDecode` 从顶点色与 UV 取出岩性、矿物、品位、线索（与 §11.6 编解码器同一份布局，改布局两边一起改）。
- **索引不能插值**：每个三角形三个顶点各带一个索引，shader 里对三个索引分别采样再按重心坐标混合
  （需要把三个顶点的索引都传到像素：用 `MultiIndex` 配置让插件负责，或在网格生成后补一个「三角形内索引」属性）。
  原型阶段 0 先比较这两条路，选定后写进设计规格。
- **贴图**：岩性 → 贴图数组（Texture2DArray）的层号，三平面映射；矿物叠在岩性之上，按品位控制覆盖度；
  线索（蚀变色、铁帽、盐壳、红土）作为颜色与粗糙度的调制层，按线索强度混合。
- **远观补细节**：远处直接采样 §11.7 的线索 cubemap，与近处的体素材质按距离淡入淡出。

### 13.12 粗 LOD 的材质聚合

- 问题：插件在粗 LOD 下按粗网格点采样材质，一个体素代表很大体积，点采样会随相机移动闪烁，稀有线索随机出现或消失。
- 建议规则：
  1. 粗 LOD 下岩性取**区域主导岩性**：由烘焙期的二维「主导岩性图」给出，而不是点采样。
  2. 矿物与品位在粗 LOD 下**不显示**（玩家在远处本来就看不到具体矿），只保留线索。
  3. 线索按「区域内最强线索」聚合，同样来自烘焙的线索 cubemap。
- 求值器从 `GetMaterialImpl` 的 LOD 参数判断走哪条路，阈值 LOD 可配。

### 13.13 对外契约

地质模型对其它系统只暴露下面这些查询，阶段 B 换地形时它们只依赖契约：

| 使用方 | 需要的查询 |
|---|---|
| 水系统（另设计） | 海平面参考高程；地表高程场；河谷网络（中心线 + 宽度 + 流量场）；内流盆地轮廓 |
| 大气 | 最低 / 最高地表半径（现有「最低地表半径」口径） |
| 地表射线、着陆、角色 | 某方向的地表半径（解析，不走体素） |
| 生物群系、天空 | 气候场（温度、降水、生物群系类型） |
| 编辑 / 挖掘 | 单点 `FGeoSample`（产出计算） |
| 存档 | 模型哈希 |

### 13.15 跨平台确定性（建议）

- 单机阶段要求「同一构建、同一机器」确定即可。
- 若将来要联机或分享种子：烘焙期改用定点数或严格浮点（不开快速数学、固定运算顺序），
  并发烘焙的结果合并顺序固定；求值期只要读的是同一个模型就天然一致。
- 建议先在烘焙期守住「固定顺序 + 不依赖线程调度」，成本低，以后升级不用重写。

### 13.16 补齐后仍需用户决定

- 3A / 3B 是否按提案加入（影响层编号与阶段划分）。
- 星球类型的范围：第一版是否只做类地星球。
- 资源以元素为单位（§13.6）还是以矿物为单位。
- 矿不改形状（§13.7）、矿物透视只留编辑器（§13.9）是否接受。
- 平衡目标的具体数值。
