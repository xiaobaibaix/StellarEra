# 地质系统设计文档

版本：1.0
模块：`VoxelPlanet/GeologySystem`

---

## 一、它解决什么问题

玩家要能**看出哪里有矿、判断是什么矿、决定要不要挖**。

如果哪里都是矿、每种矿浓度差不多，就没有探索动机——
那不叫矿脉系统，只叫资源计数器。

### 设计目标

1. **看得见** — 从太空或地表能看出矿脉分布
2. **分得出** — 能区分纯矿脉和混杂区
3. **找得到** — 稀有矿要花心思才能碰到
4. **有层次** — 有的露天，有的要挖开半边山

---

## 二、核心思路：六张地质图混合成成分向量

**这是整个系统的基础。**

不给"某点有多少铁"这种单一数值，而是给一个六维成分向量：

```cpp
FGeologySample {
    Weights[铁], Weights[铜], Weights[硅],
    Weights[钛], Weights[铀], Weights[水],
    TotalWeight,   // 总和（未归一化）
    Purity,        // = Max / Sum
    DominantGem,   // = ArgMax
};
```

每个矿种有**自己独立的一张分布图**，在采样点逐张求值，混合起来。

### 为什么是混合而不是单一数值

因为真实的矿藏**本来就是混合的**。

一处矿脉可能是「铁 55%、铜 25%、硅 15%」，
这决定了两件事：
- 它**长什么样**（颜色）
- 它**能产出什么**（分离方向）

单一数值表达不了这个。

## 三、单张地质图的构成

```
Weight = GlobalWeight × 高斯深度剖面 × 空间噪声
```

### ① 全局权重 GlobalWeight

这颗星球**总共有多少**这种矿。

由星球预设决定：岩石星球铁 0.75、金属星球铁 0.95、贫瘠星球只有 0.08。

某些矿可以直接 `bPresent = false`——这个星球压根没有。

### ② 深度剖面（高斯分布）

```cpp
DepthFactor = exp(-((Depth - PeakDepth) / LayerThickness)²);
```

`PeakDepth` 处权重最高，向上向下按 `LayerThickness` 衰减。

**用高斯不用线性**：中心厚、边缘薄、快速衰减，天然符合直觉。
线性衰减会出现明显的"矿层边界"。

### ③ 空间噪声

```cpp
SamplePoint = (UnitDir.X, UnitDir.Y, UnitDir.Z + Depth/Thickness * 0.3);
Spatial = Lerp(1.0, Noise01, SpatialVariance);
```

让矿脉**成块**而不是均匀分布。

**关键：深度必须混进 Z 分量。** 否则同一半径上的所有点会得到
相同的噪声值，结果是一层均匀的矿壳而不是矿脉。

`SpatialVariance = 0` 完全均匀，`= 1` 完全由噪声决定。

## 四、露天矿：同一公式的不同参数

这是本设计最优雅的地方——**「露出一点迹象」和「挖开才看得见」
不需要任何额外规则**，只是 `PeakDepth` 的差异。

| 矿 | PeakDepth | 地表表现 |
|---|---|---|
| 水 | -12 | 全在地表 → 到处河湖 |
| 铁 | -30 | 浅层 → 大片露天矿 |
| 硅 | -48 | 中浅 → 常见露头 |
| 铜 | -65 | 中等 → 偶尔露出 |
| 钛 | -110 | 深层 → 地表看不出，挖开半边山才碰到 |
| 铀 | -190 | 极深 → 必须深挖 |

```
深度 -190 ────────── -110 ──── -65 ── -48 ── -30 ── -12 ── 0 (海平面)
   铀层                钛层        铜    硅    铁     水
   ↑ 必须深挖                      ↑ 偶尔露头  ↑ 大片露天
```

**玩家想找铀 → 得深挖。想找铁 → 走两步就能看到红色露头。**
这个差异完全来自配置，没有一行 if-else。

## 五、层厚系数 0.65（本系统最关键的参数）

### 问题

高斯分布的**尾部无限延伸**。如果层厚接近峰值间距，
各矿的尾部会互相叠加，把主矿淹掉。

初版给的是「固定层厚 100~220」，实测结果：

```
铁的峰值处：自身权重 0.75，总权重 2.28 → 纯度仅 0.33
```

**整个星球全是灰褐混杂岩，玩家看不到任何纯矿脉。**

### 解法：层厚 = |PeakDepth| × 系数

用独立测试扫了四个系数（400 个采样点）：

| 系数 | 结果 |
|---|---|
| 1.0 | 全部混杂岩，纯度 0.33，看不出是什么矿 |
| 0.35 | 全部纯矿，纯度 0.99，没有混杂感 |
| **0.65** | **高/中/低纯度三类都有** ✓ |
| 0.80 | 偏混杂，纯矿太少 |

最终分布：0.4-0.5 有 8 个点、0.5-0.6 有 366 个、0.6-0.7 有 26 个。

**0.65 让相邻矿种部分重叠但不完全淹没。**

### 这个值是测出来的，不是拍的

```bash
clang++ -std=c++17 Tests/GeologyTest.cpp -o test && ./test
```

测试会打印纯度直方图，一眼看出分布是否合理。

**教训：高斯分布做分层时，层厚必须显著小于峰值间距**，否则尾部淹没一切。

## 六、纯度与颜色

### 纯度定义

```cpp
Purity = Max(Weights) / Sum(Weights);
```

- 接近 1 → 纯矿，一眼认出
- 接近 0 → 混杂矿，看不出是什么

### 为什么 Weights 不归一化

如果归一化到总和 1，就无法区分：

- 贫瘠矿区（总和 0.1，但比例很纯）
- 富矿区（总和 0.9，比例也很纯）

两者**比例一样但价值天差地别**。

所以：
- `Weights` 保留原值 → 表达"整体浓度"
- `Purity` 由它算出 → 表达"纯不纯"
- `bWorthMining = TotalWeight >= MiningThreshold` → 双重门槛

### 颜色映射

```cpp
ColorMix = (Purity - (1 - PurityForFullColor)) / PurityForFullColor;
Color = LerpUsingHSV(MixedRockColor, GemColor, ColorMix);
```

| 纯度 | 表现 |
|---|---|
| 0.22 | 几乎全是灰褐，看不出是什么 |
| 0.55 | 矿色但发灰，能看出倾向 |
| 0.75+ | 完全本色，一眼认出 |

**露天矿额外 ×1.15 提亮**，让地表露头比埋藏矿更明显。

### 矿种本色

| 矿 | 颜色 |
|---|---|
| 铁 | 赭红 `RGB(0.55, 0.28, 0.16)` |
| 铜 | 翠绿 `RGB(0.20, 0.52, 0.28)` |
| 硅 | 灰白 `RGB(0.62, 0.62, 0.66)` |
| 钛 | 蓝灰 `RGB(0.38, 0.46, 0.55)` |
| 铀 | 暗紫 `RGB(0.45, 0.30, 0.55)` |
| 水 | 水蓝 `RGB(0.25, 0.50, 0.75)` |

## 七、与体素星球的接口

系统是**纯计算类**：不持有 Actor、不需要世界上下文。

```cpp
FGeologySystem Geology;
Geology.Init(PlanetConfig);

// 生成器材质阶段
FGeologySample S = Geology.SampleComposition(VoxelPos, SurfaceRadius);
FLinearColor C = Geology.GetGeologyColor(S, bIsOutcrop);

// 挖掘机
EGemType Yield = Geology.DetermineYield(S, BaseYield, OutAmount);
float Difficulty = Geology.GetDigDifficulty(S, Depth);
```

### 矿脉怎么在体素上体现

当前 `MaterialConfig = RGB`，每个体素只有一个纯色。所以：

| 方案 | 做法 | 状态 |
|---|---|---|
| **A. 地表染色** | `GetMaterialImpl` 查矿脉，染成主矿色 | 待接 |
| **B. 挖开暴露** | 地表照常，挖开后新体素按矿脉染 | 待接 |
| C. MultiIndex | 改材质配置，精确存成分比例 | 需要大改 |

**建议先做 A。** 零成本，飞行时一眼看出哪里富矿。

### 性能约束

`GetMaterialImpl` **每体素调一次**。6 种矿各自采样 → 6 次噪声，
相对现在（1 次）约 7 倍开销。

**对千万体素的星球不可接受。** 三个解法：

| 方案 | 成本 |
|---|---|
| A. 降频采样（只对 LOD≥2 算完整成分） | 有 LOD 跳变 |
| **B. 按整数块缓存成分** | 需要缓存管理 |
| C. 只算主矿（低频选出主矿再细分） | 精确度下降 |

**推荐 B**——成分在空间上连续，8×8×8 块内几乎相同。

### 5 组测试

| # | 验证什么 | 为什么重要 |
|---|---|---|
| 1 | 浅层矿地表有浓度，深层矿地表≈0 | 露天矿设计是否生效 |
| 2 | 深挖能碰到深层矿 | 深埋矿是否可获取 |
| 3 | 同坐标两次采样完全一致 | 不能有随机数 |
| 4 | 不同种子 → 不同布局 | 每颗星球矿脉不同 |
| 5 | 纯度范围与分布 | 纯矿/混杂矿是否都有 |

**这些能在进 UE 之前发现数学错误**，成本极低。
