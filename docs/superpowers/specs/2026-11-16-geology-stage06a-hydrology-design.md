# 地质阶段 6a：水系与剥蚀 设计

> 上位规格：`2026-11-12-geology-pipeline/06-erosion.md`。阶段 6 拆三步：6a 水系与剥蚀（本文）、6b 出露结算、6c 沉积矿床。
> 本步只算水系、刻河谷、出剥蚀深度场；不撒矿、不改原语。

## 1. 目标与非目标

**目标**
- 新增 `FStage06Erosion`（阶段号 6），在宏观网格上做填洼、内流盆地判定、D8 流向、按降水加权的汇流累积。
- 汇流量超过阈值的格子是河道；按河道中心线在全分辨率高程上刻出 U 形谷。
- 产出剥蚀深度场 `ErosionDepth`（只供 6b 计算出露，不再压低高程）。
- 注册四个调试图层；参数进配方 `Stage6|Hydro`、带中文注释、进哈希。

**非目标**
- 不生成水体（湖面、河面）。
- 不做出露结算（6b）、不撒沉积矿（6c）。
- 不做岩性硬度差异（无 3A 岩性层）。

## 2. 与上位规格的差异

| 上位规格 | 本步 | 原因 |
|---|---|---|
| 尺寸按 R=500 的「格」 | 全部占半径比例 | 半径可变 |
| 河谷与盆地是体素差集 | 河谷刻进 2D 高程场；盆地不改几何 | 与阶段 3 / 4a 一致，体素求值与值域不用改 |
| 内流 = 无出口洼地 | 内流 = 洼地集水区平均降水 < 阈值 | 球面上 priority-flood 后所有洼地都有溢出口；是否溢出取决于来水与蒸发 |
| 剥蚀改地形 | 剥蚀只是一张场 | 阶段 3 的高程已是被侵蚀后的现今地表；剥蚀深度只用于反推出露 |

## 3. 网格

- 水系网格 = 宏观分辨率 `HydroRes = max(64, FaceRes / 4)`（默认 256），6 面共 `6·HydroRes²` 格。
- 格子编号 `Idx = (Face·Res + Y)·Res + X`；8 邻域跨面时：取邻居 texel 中心方向，`DirToFace` 换回所在面的格子。邻居表预计算一次（`TArray<int32>` 6·Res²·8），之后所有遍历只查表。
- 每格面积按立体角权重（`GeoContinentField::TexelWeight`）。

## 4. 算法

记 `R = Cfg.Radius`，`E` 为宏观网格上的高程（从全分辨率 `Elevation` 采样）。

1. **填洼（priority-flood）**：所有 `E ≤ 0` 的格子入最小堆作为种子，`Filled = E`。弹出最低格，对每个未访问邻居 `Filled[n] = max(E[n], Filled[cur] + ε)`，入堆。`ε = FlatSlopeRatio · R · 格距`，保证填平区仍有极小坡度、流向唯一。`Depth = Filled − E`；`Depth > 0` 的连通块是一个洼地，记下它的溢出格（填平时第一次越过洼地边缘的格子）。
2. **流向**：每格取 8 邻域中 `Filled` 最低且低于自己的那个；海洋格子（`E ≤ 0`）没有下游。平手按邻居编号小者优先（确定性）。
3. **内流盆地判定**：对每个洼地，计算其上游集水区（所有最终流入该洼地的格子）面积加权平均降水；`< EndorheicPrecip` → 内流盆地，**切断该洼地溢出格的流向**（水流在洼地里终止）；否则为湖盆，流向保持。分类一律按切断前的累积判定，位于内流盆地下游的湖盆集水区因此含有被切走的水，6a 接受这一简化。`BasinMask`：0 无 / 1 湖盆 / 2 内流盆地。
4. **汇流累积**：按 `Filled` 从高到低排序遍历（拓扑序），`Acc[i] = Area[i]·Precip[i] + Σ Acc[上游]`；再除以全球总面积得到 0–1 量级。
5. **河道**：`Acc ≥ RiverThreshold` 的陆上格子为河道。`RiverMask = SmoothStep(Thr, 4·Thr, Acc)`。
6. **下切**：河道格子 `Carve = CarveRatio · R · sqrt(Acc / Thr) · sqrt(Slope / SlopeRef)`，上限 `CarveMaxRatio · R`，且陆上 `E − Carve ≥ 1`。谷半宽 `HalfWidth = ValleyWidthRatio · sqrt(Acc / Thr)`（方向单位）。
7. **刻谷**：河道中心线 = 每个河道格子到其下游格子的线段。全分辨率每个 texel：找桶内线段，到线段距离 `d`，`Profile = (1 − smoothstep(0, 1, d / HalfWidth))²`（U 形），`Elevation -= Carve · Profile`（多条线段取 max）。线段按宏观格子分桶，避免全量遍历。
8. **剥蚀深度**：`ErosionDepth = ErosionRatio · R · Precip · clamp(Slope / SlopeRef, 0, 2) · (0.3 + 0.7 · MountainMask) + Carve`，只在陆上；海底为 0。

统计量（Min/Max 高程、陆地占比）在刻谷后重算。

## 5. 参数（配方 `Stage6|Hydro`）

| 参数 | 默认 | 含义 |
|---|---|---|
| `bRivers` | true | 是否刻河谷 |
| `RiverThreshold` | 0.0008 | 成为河道的最小汇流量（占全球「面积 × 降水」） |
| `CarveRatio` | 0.002 | 下切强度（占 R） |
| `CarveMaxRatio` | 0.008 | 最大下切深度 |
| `ValleyWidthRatio` | 0.006 | 谷半宽（方向单位，随汇流增大） |
| `SlopeRef` | 0.02 | 坡度参考值（高程差 / 弧长） |
| `ErosionRatio` | 0.01 | 剥蚀强度（占 R） |
| `EndorheicPrecip` | 0.3 | 洼地集水区平均降水低于它即为内流盆地 |
| `FlatSlopeRatio` | 1e-6 | 填洼后保留的极小坡度 |
| `MountainErosionWeight` | 0.7 | 山带遮蔽对剥蚀的加权 |

全部进 `Hash()`，`ToConfig` 透传。

## 6. 调试图层

- `FlowAccum`：连续，按 `log10` 着色（白→深蓝）。
- `BasinMask`：分类 3 档（无 / 湖盆 / 内流盆地）。
- `ErosionDepth`：连续，体素。
- `RiverMask`：连续 0–1。

`ExportDebugFields` 导出四张场。

## 7. 测试（`Src/Tests/PlanetGeoStage06Tests.cpp`）

1. **无断头河**：从每个河道格子顺流向走，必须在有限步内到达海洋格子或内流盆地格子。
2. **汇流单调**：沿流向下游的 `Acc` 不小于上游。
3. **盆地判定**：每个湖盆都有溢出格且溢出格有下游；每个内流盆地的集水区平均降水 < 阈值。
4. **下切只降不升**：刻谷后每 texel 高程 ≤ 刻谷前；陆地占比变化 < 0.005；陆上没有被刻到海平面以下。
5. **山带剥蚀更强**：`MountainMask > 0.5` 的格子平均剥蚀 > `MountainMask < 0.1` 的 2 倍。
6. **确定性与尺度**：并行 / 单线程四张场哈希一致（逐位）。半径减半：`BasinMask` 与河道格子集合差异 ≤ 0.5% 格子，`FlowAccum` 相对误差中位数 ≤ 1e-3，`ErosionDepth` 与下切深度按体素减半（相对误差中位数 ≤ 1e-3）。不要求逐位：上游高程的 0.01 体素绝对下限不随半径缩放，会翻转填洼的平手顺序（见 §8）。
7. 配方哈希探针 + 全字段透传（非默认值）。

## 8. 风险

- priority-flood 是 O(N log N)，N = 39 万，单线程约几十毫秒；不能并行，属可接受。
- 汇流累积需要拓扑序：按 `Filled` 降序排序即可（`Filled` 沿流向严格递减，ε 保证）。
- 内流判定要先算集水区：先按「不切断」做一次累积求每个洼地的集水平均降水，再切断内流洼地的出口重做累积。两次 O(N)。
- 刻谷分桶：线段约数千条，按宏观格子分桶，每个全分辨率 texel 只查本格与 8 邻格。
- 尺度不变：上游高程带 0.01 体素绝对下限（阶段 5 已记录），`Filled` 的平手顺序可能随半径翻转；测试按阶段 5 的容差口径判，不要求逐位。
- 河谷半宽按公式生效，分桶圈数由最宽的谷决定（2–4 圈）；半宽上限 (圈数−0.5)×宏观格弧长，即最多约 4 个宏观格，更宽的谷被截到上限。
