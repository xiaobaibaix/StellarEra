# 阶段 2：板块构造与陆块

> 类型：2D 烘焙（非局部） / 改密度：**是**（陆块基准 + 接缝过渡）
> 撒矿：条带状铁矿、绿岩带金、科马提岩镍、洋中脊硫化物、锰结核
> 最小可辨：板块 ≥ 10 格宽，陆坡 ≥ 2 格宽，海岸线可辨需烘焙 cell ≤ 1.5 格
> **基准（2026-11-12 定）**：海平面 ≡ `R₀`（标准球面）≡ 陆块场 `M = 0.5` 等值面

## 职责

本阶段一次产出三样，同批冻结：

1. **构造框架**——板块划分、边界位置、边界类型、地壳年龄
2. **陆块形状**——哪里是陆、哪里是洋、海岸线在哪
3. **宏观基准高程**——`ElevationBase`，只有「陆台」和「洋盆」两级，不含山脉与细节

为什么本阶段必须动密度：如果把陆海格局全推给阶段 3，那「大陆在哪」这个最需要反复调的东西就落在阶段 3 里，而阶段 3 是全项目回归面最大的模块（水文、水面、大气、地表射线、群系 cubemap 全读它）。**调大陆轮廓不该动最贵的模块。**

## 输入

| 键 | 来源 |
|---|---|
| `RadialProfile`（半径、背景岩性） | 1 |

## 输出

| 键 | 类型 | 说明 |
|---|---|---|
| `PlateId` | 球面场 int8 | 0–63 |
| `BoundaryType` | 球面场 uint8 | 0 无 / 1 汇聚-洋陆 / 2 汇聚-洋洋 / 3 汇聚-陆陆 / 4 离散 / 5 转换 |
| `BoundaryDistance` | 球面场 float | 到最近边界的测地距离，归一化到 R |
| `CrustAge` | 球面场 float | 0 = 现代洋壳，1 = 最老克拉通 |
| `ContinentalMask` `M` | 球面场 float | 陆块场，`M=0` 洋、`M=1` 陆、`M=0.5` 海岸线 |
| `ContinentalGrad` | 球面场 float | `\|∇M\|`，供海岸线距离换算 |
| `CrustType` | 球面场 uint8 | 0 洋壳 / 1 陆壳 / 2 陆坡，由 `M` 阈值切 |
| `CrustThickness` | 球面场 float | 归一化：0 = 洋壳 7 km，1 = 造山带 70 km |
| `ElevationBase` | 球面场 float | **本阶段唯一改密度的输出**，单位：格 |

`CrustType` 从 `M` 切、不从 `PlateId` 查——**板块 ≠ 大陆**。一块板块可以同时有陆有洋（欧亚板块既有喜马拉雅也有西太平洋边缘海），也可以是纯洋（太平洋板块）。把两者焊死，被动陆缘、陆表海、陆内盆地就全部没有输入了。

## 生成逻辑（六步）

### 第 1 步 · 板块划分

Fibonacci 球面点 `N ∈ [6,15]`（默认 7）+ 抖动 → **加权** Voronoi。

权重必须是乘性而不是加性，否则 7 块板块面积相同，出不了太平洋那种巨型板块：

```
dist_p(dir) = geodist(dir, c_p) / w_p          // w_p ∈ [0.6, 1.8]
PlateId     = argmin_p dist_p
```

种子权重按幂律抽，目标最大板块面积占比 25–40%。

### 第 2 步 · 板块分类

按种子权重随机抽：**大陆型 ×3 / 大洋型 ×3 / 混合型 ×1**（比例可配）。这个分类只影响第 3 步铺核的期望数量，不直接决定高程。

### 第 3 步 · 铺陆核

| 板块类型 | 陆核数 | 核半径 |
|---|---|---|
| 大陆型 | 2–4 个 | `r_i = α · 0.12R` |
| 混合型 | 1–2 个 | 同上，可跨板块边界 |
| 大洋型 | 0 个（15% 概率 1 个微陆核） | `≤ 0.05R` |

- 核位置用 Poisson 盘采样，核间距 ≥ `0.25R`
- 允许核跨板块边界（真实大陆常横跨板块缝合线）
- 全星核数落在 **9–14** 个；`R < 150` 时降到 6–9 个，否则铺不下

### 第 4 步 · 陆块场

高斯团求和再 clamp，天然是「平滑并集」——重叠处自动隆起成高原，不会出现凹角：

```
d_i(dir) = |dir − c_i| − r_i                        // 到第 i 个核的有符号距离
M(dir)   = clamp( Σ_i exp(−d_i² / 2σ_i²), 0, 1 )    // σ_i = 0.55 · r_i
```

`α` 是全局半径缩放，由第 6 步反解。

**噪声在这里不出场。** 噪声天生零均值、处处平均，它能做质感，做不了「这里有块陆」这种决定。如果用零均值噪声当主控，得到的是陆海碎斑，不是大陆（见验收 1 的穿越次数指标）。

### 第 5 步 · 海岸线与高程

把 `M` 转成「到海岸线的有符号距离」，再用两段 smoothstep 映射成两级台阶：

```
t   = (M − 0.5) / max(ContinentalGrad, ε)           // 近似到 M=0.5 等值面的距离，单位 R
h_base = A_up  · smoothstep(0, w_s, +t)
       − A_down · smoothstep(0, w_s, −t)
```

| 参数 | 含义 | 取值 |
|---|---|---|
| `A_up` | 大陆台面高出海平面 | `clamp(1.2%R, 3, 12)` 格 |
| `A_down` | 洋盆低于海平面 | `2 · A_up` 格 |
| `w_s` | 陆坡宽度 | `clamp(0.6%R, 2, 6)` 格 |

`A_down` 取 2 倍而**不是真实的 5 倍**：真实比例下洋底要沉 30 格（R=500），玩家掉下去看不见光；2 倍时陆海高差约 18 格，俯视一眼能读出陆海边界，同时还能潜下去。

两段台阶的中间带（`|t| < w_s`）就是**陆架 → 陆坡 → 深海平原**的入口，阶段 3 的被动陆缘剖面接这里。

### 第 6 步 · 反解 α

海平面钉在 `R₀` 之后，海洋占比不再是自由变量，必须反解：

```
二分 α ∈ [0.5, 2.0]，使 area{ M > 0.5 } = targetLandFrac
```

- `targetLandFrac ∈ [0.25, 0.35]`，默认 0.30
- 用 64×64 低分辨率球面场估面积，5–8 次迭代收敛，成本可忽略
- 收敛后**再用全分辨率烘焙一次**，不要拿低分辨率的场去用

这一步替代了「海平面标定」。跳过它，不同 seed 的星球陆地占比会在 8%–70% 之间乱跳。

### 第 7 步 · 板块专属风格（接缝过渡）

陆块项是全局场，天然连续；真正需要接缝处理的是**板块专属的中低频起伏**——不同板块的地形粗糙度应该有差别。

```
w_p(dir) = clamp( distToOutside_p(dir) / w , 0, 1 )
W_p(dir) = w_p / Σ_q w_q                              // 单位分解，ΣW_p ≡ 1

h_style = Σ_p  W_p · ( Δ_p + amp_p · fBm_低频(local_p(dir)) )
```

| 参数 | 取值 | 说明 |
|---|---|---|
| `Δ_p` | `±0.2 · A_up` | 板块整体微调，制造「这块略高」的差别 |
| `amp_p` | `clamp(0.4%R, 1.5, 4)` 格 | 与板块活动性正相关 |
| `w` | `clamp(0.8%R, 2, 8)` 格 | 接缝过渡宽度，**不小于 2 格** |

三条硬约束：

1. **必须归一化。** 直接 `Σ w_p·h_p` 而不除以 `ΣW`，在两块板块相遇处碰巧 `w₁+w₂≡1` 看不出问题，但**三板块交汇点**处每块离自己边界都近，三个 `w` 都只有 0.3 左右，`Σw ≈ 0.3` → `H` 塌向 0 → 每个三节点留一个零高程凹坑。7 块板块必然出现若干三节点。
2. **不要用 `max` / `min` 叠加。** `max` 会把低于基准面的洋盆裁平成基准球面（换 `min` 又把大陆裁掉）；而且两块独立噪声取较大值的期望恒高于两者，每条边界都会抬出一圈假脊。
3. **过渡宽度 `w` 不能小于 2 格**，再窄就是折角，等于没做过渡；也不能大于 8 格，否则小半径星球上整块大陆都被过渡带污染。

最终：

```
ElevationBase = h_base + h_style
```

噪声基频固定为**每半球 1.5 个波长的超低频**（fBm 2–3 octave），与 R 无关——如果用绝对频率，R 一变大陆数量就跟着变。

## 撒矿

本阶段的矿不是「随机分布」，而是**位置由场决定，只有 seed 是随机**。随机感来自板块形状本身是随机的（Voronoi 种子 + domain warp），不来自矿点跳动。这两者的区别在于：前者玩家能读出规律，后者不能。

| 矿 | 条件 | 形态 | 规模 |
|---|---|---|---|
| 条带状铁建造 BIF | `CrustType=陆` 且 `CrustAge > 0.8` | 层状，随地层走向 | 20–60 格长，2–4 格厚 |
| 绿岩带金 | 克拉通边缘的绿岩带线状体 | 线状带 + 石英脉 | 长 30 格，宽 2 格 |
| 科马提岩镍 | 绿岩带底部 | 扁透镜（压扁团块） | 4–8 格 |
| 块状硫化物 VMS | `BoundaryType ∈ {1,2}` 且到脊线 < 2 格 | 成串离散透镜 | 3–6 格，间距 8–15 格 |
| 锰结核 | `CrustType=洋` 且 `CrustAge > 0.7` 且远离陆源 | 面状薄层 | 1 格，只能走材质 |

前四类全部绑定岩性或构造域，没有一类是「全域均匀撒点」。

## 值域

本阶段继承**值域义务**。`ElevationBase` 的保守界：

```
|ElevationBase| ≤ A_up + A_down + amp_max + |Δ|_max
              ≈ 3.2 · A_up + amp_max
```

| R | `A_up` | `amp` | 阶段 2 引入带宽 | 占 R |
|---|---|---|---|---|
| 100 | 3 | 1.5 | ≈ 11.1 格 | **11.1%** |
| 250 | 3 | 1.5 | ≈ 11.1 格 | 4.4% |
| 500 | 6 | 2 | ≈ 21.2 格 | 4.2% |
| 1000 | 12 | 4 | ≈ 42.4 格 | 4.2% |

**小半径的相对成本高得多。** `R=100` 时本阶段一项就吃掉 11%，而总准入线是 15%——剩给阶段 3/4/6/7 只剩 4%，必然超。所以在 `R < 150` 时只有两条路：把 `A_up` 下限压到 2 并接受低起伏，或直接放弃「任何深度都能挖」这条。

## 分辨率现实

- **烘焙分辨率**：球面 cell = `2πR / (4·faceRes)`，要分辨 1.5 格的陆坡，需要
  `faceRes ≥ πR/3` → `faceRes = clamp(nextPow2(πR/3), 128, 1024)`（上限 1024，理由见 `20-architecture.md` §3.3：2048 会让快照涨到 200 MB/星球）。
  现有水文复用的 512 只覆盖到 `R ≤ 489`，R 一过 500 就要提到 1024，否则海岸线是台阶状。
- **陆核半径** `0.12R`：R=500 时 60 格、R=100 时 12 格，都还在可辨范围；`R < 80` 时单核不足 10 格，要减核数。
- **板块数** < 6 时单块太大、弧火山排成直线；> 15 时边界太多、处处是山。
- **接缝过渡** `w` 最窄 2 格，这是硬下限。

## 验收

1. **穿越次数**：沿任一测地线（大圆）走一圈，`ElevationBase` 穿越海平面的次数 **≤ 6–10 次**。
   穿越 40 次 = 陆海碎斑；穿越 3 次 = 一整颗只有一块陆。这条比目视可靠，且能自动化。
2. **陆地占比**：`area{M>0.5}` 与 `targetLandFrac` 误差 ≤ 2%，反解迭代 ≤ 8 次。
3. **无假脊**：沿每条边界取 50 个采样点，跨边界 ±`w` 范围内 `ElevationBase` 沿法线方向的一阶差分单调不过零。
4. **无凹坑**：所有三板块交汇点处 `ΣW ≡ 1`（误差 < 1e-3），且该点高程不得低于周围 3 格内的最小值。
5. **无缝**：极点与 cubemap 接缝处 `M`、`ElevationBase` 连续。
6. **年龄场**：从洋中脊对称递减，无跳变。
7. **确定性**：同配方连烘两次，输出哈希一致。
