# 撒矿规则

规则是**数据**，不是代码。加一个矿 = 加一份 `minerals/*.md` + 一条规则，不改 C++。

## 1. 规则结构

```
Rule
├─ Id                 唯一名，如 "sulfur_active_volcano"
├─ Stage              挂在哪一阶段之后（= 条件全部就绪的最早一层）
├─ Conditions[]       对黑板键的谓词组合（AND）
├─ Placement          在哪生成实例
├─ Primitive          形态原语 + 尺寸 / 走向来源
├─ Grade              峰值品位 + 剖面 + 每矿种自己的刻度上限
├─ Element            矿物 → 元素换算（产出用）
├─ Clue[]             地表 / 围岩 / 仪器线索
└─ Seed               派生：Hash(层种子, 规则 Id)
```

## 2. 条件谓词

| 谓词 | 例 |
|---|---|
| `Eq / Ne` | `BoundaryType == 汇聚-洋陆` |
| `InRange` | `BoundaryDistance ∈ [18, 24]` 格 |
| `Greater / Less` | `CrustAge > 0.9` |
| `Has` | 该点附近存在某类基元（活火山、石灰岩层） |
| `WithinOf` | 到某基元的距离 < N 格 |
| `And / Or / Not` | 组合 |

**所有谓词只能读黑板里已有的键**。调度器在烘焙前做静态检查：
读了没人写的键 → 直接报错，不允许运行时静默返回 0（那会让规则永远命中 0 个矿而没人发现）。

## 3. 放置方式

| 方式 | 用于 | 实现 |
|---|---|---|
| `ScatterByArea` | 面状散布（锰结核、红土） | 按面积密度撒点 + 泊松盘去重 |
| `AlongLine` | 线状（弧火山硫磺、洋中脊硫化物） | 沿边界线等距 + 抖动 |
| `AroundPrimitive` | 依附（浅成金银在火山下、矽卡岩在接触带） | 以基元为锚，偏移固定相对位置 |
| `InField` | 场阈值内（盆地中心的盐、河谷底的砂） | 采样球面场，超阈值处撒点 |
| `AtPoint` | 定值（地核铁镍） | 直接挂径向区间 |

## 4. 品位：三个量纲分开

| 概念 | 存哪 | 单位 | 谁用 |
|---|---|---|---|
| 背景含量 clarke | `Background`（阶段 1） | ppm / % | 解释「为什么这里本来就有」 |
| 品位 grade | 材质 `B` 通道 | 0–255，**每矿种自己的刻度** | 挖矿产出 |
| 规模 / 面密度 | 规则的撒点参数 | 每 km² 几个、单个体积 | 平衡 |

品位的 0–255 必须按矿种映射，不能共用刻度：

```
Grade8 = round(clamp(GradeReal / GradeMax_Mineral) * 255)
// 金：GradeMax = 5 g/t   → 255 表示 5 g/t
// 铁：GradeMax = 60%      → 255 表示 60%
// 铜：GradeMax = 1%       → 255 表示 1%
```

## 5. 线索

| 字段 | 说明 |
|---|---|
| `ClueType` | 0–15（蚀变分带 / 铁帽 / 硫磺 / 盐壳 / 红土 / 重砂…） |
| `ClueStrength` | 0–15，按到矿体的距离衰减 |
| `ClueRange` | 线索扩散半径（格） |
| `Reliability` | 有线索处真有矿的概率（难度旋钮，多数金伯利岩管不含金刚石） |
| `Instrument` | 哪种仪器能读到（磁力 / 重力 / 元素 / 只有钻探） |

线索写进材质的 `A` 通道，**不依赖粒子与植被**。

## 6. 校验（烘焙期必跑）

| 检查 | 失败处理 |
|---|---|
| 读空键 | 报错，拒绝烘焙 |
| 规则产出 0 个实例 | **标红警告**（多半是条件写错） |
| 品位 > 刻度上限 | 报错 |
| 矿体越界（穿出地表/穿出地核） | 报错 |
| 线索无对应矿体 | 警告（除非 `Reliability` 故意设计） |
| 同一体素被两个矿同时占据 | 按规则 `Priority` 取高，警告 |
| **陆海穿越次数 > 10 / 大圆** | **标红警告**（多半是把陆块场写成了零均值噪声，见 `02-plates.md` 验收 1） |
| **陆地面积偏离 `targetLandFrac` > 2%** | 报错（反解 α 未收敛，矿会撒在错的海陆分布上） |
| 阶段 2 以上规则的命中点全部落在水下 | 警告（说明海平面或陆台高度算错了） |

## 7. 叠加冲突

一个体素可能同时属于两个矿体（斑岩铜 + 次生富集铜）。
规则：

1. 显式 `Priority`（高覆盖低），默认按阶段号（后阶段覆盖前阶段）。
2. 主矿物 = 优先级最高的；次矿物写 `U0/V0`。
3. 三个以上同时命中 → 只保留前两个，第三个丢弃并警告（说明规则条件重叠了）。
