# 阶段 4：岩浆活动

> 类型：3D 基元 / 改密度：**锥并 / 口差** / 撒矿：**本阶段是矿产主力，10 种以上的矿**
> 最小可辨：火山锥底 ≥ 24 格、岩株 ≥ 4 格、金伯利管 2 格（做成小团块）

## 职责

生成火山与侵入体的**点表 + 三维形状**，并沿「竖直矿柱」撒矿。
这是「地表线索 → 地下矿」机制最强的一层，也是**第一个竖切要做的层**。

## 输入

| 键 | 来源 |
|---|---|
| `BoundaryType` `BoundaryDistance` `PlateId` `CrustType` | 2 |
| `Elevation`（判断是否在水下、剥蚀量） | 3 |
| `DeepBlobs`（热点位置） | 1 |
| `ErosionDepth`（剥蚀改变出露，后置） | 6 |

## 输出

| 键 | 内容 |
|---|---|
| `Volcanoes` | 基元集：位置、类型、底径、高、火口径、是否活跃、年龄 |
| `Intrusions` | 基元集：岩基 / 岩株 / 岩墙 / 岩床 / 层状侵入体 / 金伯利管，含顶部深度 |

## 地形逻辑

**地表火山（并集；火口用差集）**

| 类型 | 位置 | 形状 | 体素尺寸（R=500） |
|---|---|---|---|
| 层状火山 | 俯冲弧，距边界 20 格 | 陡锥 ~30°，顶有火口 | 底 24、高 12、口 4 |
| 盾状火山 | 热点链 | 缓坡 5–10° | 底 40、高 8 |
| 溢流玄武岩 | 裂谷 / 大火成岩省 | 平坦台地 | 60×60、高 3 |
| 破火山口 | 大喷发塌陷 | 环形洼地 | 口 16、深 4 |
| 火山渣锥 | 火山群 | 成簇小锥 | 底 6、高 3 |

**地下侵入体（挖掘时遇到）**

| 类型 | 形状 | 尺寸 |
|---|---|---|
| 岩基 | 巨大团块，顶面穹状 | 40–80 格宽，顶部 −30 格 |
| 岩株 | 岩基顶部伸出，**斑岩矿长在这里** | 4–8 格宽 |
| 岩墙 / 岩床 | 薄板，近垂直 / 近水平 | 厚 2 格 |
| 层状侵入体 | 内部分规整水平层（全项目少有的规整平面） | 20×20×8 |
| 金伯利岩管 | 胡萝卜形竖直细管 | 直径 2 格（做不成管，改用小团块 + 材质） |

**蚀变分带**：不建几何。只写材质（`A` 通道的线索类型 + 强度）：
从内到外 `钾化 → 绢英岩化 → 泥化 → 青磐岩化`，由「到侵入体的距离 × 强度」分段。见 `11-material-field.md`。

## 撒矿

竖向矿柱是本阶段的核心机制：

```
地表：硫磺结壳（活火山、火口 4 格内）
  ↓  −2 格：浅成低温金银（脉状）
  ↓  −6~−15 格：斑岩铜（大型浸染体）
  ↓  更深处：岩基（无矿）
```

| 矿 | 条件 | 形态 | 详细规格 |
|---|---|---|---|
| 硫磺 | 活跃火山 + 火口 4 格内 | 地表结壳 / 充填 | `minerals/sulfur.md` |
| 浅成低温金银 | 火山锥顶面下 2–6 格 | 脉状（线状带） | `minerals/epithermal-au-ag.md` |
| 斑岩铜 | 岩株顶部、锥下 6–15 格 | 大型浸染体 | `minerals/porphyry-copper.md` |
| 矽卡岩 | 侵入体与石灰岩接触面 | 不规则壳 | **需 3A**，否则跳过 |
| 锡钨 | 陆-陆碰撞带花岗岩顶部 | 云英岩 + 石英脉 | 线状带，长 20 格 |
| 伟晶岩锂钽铍 | 花岗岩边缘 | 透镜 / 脉 | 2–4 格，小而富 |
| 岩浆铜镍硫化物 | 镁铁质侵入体底部 | 底部团块 + 层 | 6–10 格 |
| 层状侵入体铬铂 | 克拉通内的层状侵入体 | 薄层，横向连续 | 厚 2 格，长 20 格 |
| 金伯利岩金刚石 | 古老克拉通（`CrustAge>0.9`） | 管状 | 2 格，多数不含矿 |
| 碳酸岩稀土 | 大陆裂谷 | 小团块 | 2–4 格 |

## 值域

- 火山锥：`GetRange` 用「底径 + 高」的包围球给保守上下界。
- 侵入体：按包围盒剔除；chunk 完全在侵入体外 → 贡献 0。
- **注意**：锥体是并集、火口是差集，两者要分开给范围，否则叠加后范围过宽。

## 分辨率现实

- 蚀变 4 圈在 4 格宽的岩株上根本画不出来 → **必须走材质**。这是本阶段最重要的取舍。
- 金伯利管直径 2 格，管状形态不可读 → 用「2 格团块 + 独特材质」代替。
- 岩浆房、火山通道不做（玩家挖不到那么深，也没必要）。

## 验收

1. 每条汇聚边界都有弧火山，间距 15–25 格，不与山脉错位。
2. 硫磺**只**出现在活跃火山的火口 4 格内，别处为 0（这是用户最关心的例子，要单独写测试）。
3. 竖向矿柱：从火山顶竖直向下采样，命中顺序必须是 硫磺 → 金银 → 斑岩铜。
4. 每个火山/侵入体的包围盒都进 BVH，抽样 1000 点比对「BVH 结果 == 暴力遍历」。
