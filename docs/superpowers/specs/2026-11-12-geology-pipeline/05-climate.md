# 阶段 5：气候

> 类型：2D 场（非局部） / 改密度：**否** / 撒矿：**无，只给条件**
> 最小可辨：场分辨率 256 足够（气候是低频场）

## 职责

产出一张「哪里湿热、哪里干冷、哪里背风」的图，供阶段 6（侵蚀）和 7（风化）判断条件。
**它不改地形，也不撒矿**——但煤、盐、铝土、红土全靠它。

## 输入

| 键 | 来源 |
|---|---|
| `Elevation` | 3 |
| 配方：自转轴倾角、自转方向 | `FPlanetRecipe` |

## 输出

| 键 | 说明 |
|---|---|
| `Temperature` | float，归一化 0–1 |
| `Precipitation` | float，0–1 |
| `WindDir` | float，球面方位角 |
| `Biome` | uint8：沙漠 / 草原 / 稀树草原 / 雨林 / 温带林 / 针叶林 / 苔原 / 冰原 |

## 逻辑

```
Temperature = 纬度基础值(1 - sin²(lat))      // 赤道热、两极冷
            - 直减率 × 高程                   // ~6.5°C/km，按风格化比例换算
            ± 大陆度                          // 离海越远温差越大

Precipitation = 纬度带(赤道多雨、30° 干旱、中纬湿润、两极干冷)
              - 雨影(逆风回溯的累积抬升)
              - 离海距离衰减
```

**雨影**是本阶段唯一的非局部算法：从每个点沿逆风方向回溯，
每翻过一段抬升就扣掉一部分水汽（`p -= k · Δh · 现有湿度`）。
回溯步长 2 格，最多 32 步 —— 这个上限直接决定「山脉背后的沙漠有多宽」。

## 撒矿

无。只向下游暴露条件谓词：

| 下游矿 | 用的条件 |
|---|---|
| 煤 | `Precipitation > 0.6` 且低平 |
| 蒸发岩 / 锂盐 | `Precipitation < 0.2` 且内流盆地 |
| 铝土矿 / 红土镍 | `Temperature > 0.7` 且 `Precipitation > 0.7` |
| 高岭土 | 同上，母岩是花岗岩 |
| 砂矿风化速率 | 降水越高剥蚀越快 |

## 分辨率现实

256 分辨率 = 每格约 1.5% 球面，对应 R=500 时约 8 格。气候是低频场，够用。
不要提到 512 以上，浪费且会放大雨影回溯的抖动。

## 验收

1. 存在 30° 附近的干旱带（沙漠不是随机分布）。
2. 雨影两侧降水差 > 0.4（一边雨林一边沙漠）。
3. 极区温度 < 0，赤道 > 0.8。
4. 与 `Biome` 查表一致：同温度/降水对必须落到同一个群系。
