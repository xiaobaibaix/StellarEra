# 阶段 3：宏观地形

> 类型：2D 烘焙 + 逐体素细节 / 改密度：**高度偏移（增量）** / 撒矿：蛇绿岩铬铁
> 最小可辨：山脉 ≥ 5 格高、海沟 ≥ 2 格宽
> **基准**：海平面 ≡ `R₀`。海拔 `= |p| − R₀`，**水下为负值**，负值是合法状态。
> **本阶段内置热力侵蚀**（不依赖气候），流水侵蚀留给阶段 6。

## 职责

在阶段 2 的 `ElevationBase`（陆台 / 洋盆两级）之上加两级细节：**山带**（局部、有走向、有脊线）和**平原起伏**（低幅、各向同性）。然后做一轮**热力侵蚀**把 ridged 的尖刺磨圆。

这是全项目回归面最大的一处：`UVoxelPlanetNoiseTerrain` 的纯 fBm 被替换，水文、水面、大气、地表射线、生物群系 cubemap 全部改读它。**正因为回归面大，宏观骨架已经上移到阶段 2 冻结掉了**，本阶段只做增量。

三条设计约束，缺任何一条都会做出「橘子」：

1. **山脉是局部的。** 噪声统计均匀，全域铺 fBm 只能得到满地疙瘩——没有平原，也没有真正的山。必须有遮蔽权重。
2. **山脉有脊线。** 普通 fBm 圆润像沙丘，要用 `ridged = 1 − |noise|`。
3. **山脉有走向。** 真实山带沿走向几百公里、垂直走向几十公里，必须各向异性采样。

## 输入

| 键 | 来源 |
|---|---|
| `ElevationBase` | 2 |
| `ContinentalMask` `ContinentalGrad` | 2 |
| `CrustThickness` `CrustAge` | 2 |
| `BoundaryType` `BoundaryDistance` | 2 |

## 输出

| 键 | 说明 |
|---|---|
| `ReliefRaw` | 侵蚀前的地形增量，**值域按它估** |
| `ReliefDelta` | 热力侵蚀后的地形增量，即最终使用值 |
| `Elevation` | `ElevationBase + ReliefDelta`，最终高程 |
| `ReliefType` | 0 洋盆 / 1 陆架 / 2 平原 / 3 丘陵 / 4 高山 / 5 海沟 / 6 裂谷 |
| `MountainMask` | 山带遮蔽权重，供阶段 6/7 判「剥蚀强度」、阶段 4 判「火山弧位置」 |

`ReliefType` 由 `ReliefDelta` 与 `ContinentalMask` 联合判定，不是单独一套分类——否则会出现「高程是山、类型是平原」的自相矛盾。

## 生成逻辑（五步）

### 第 1 步 · 采样坐标扭曲

扭曲作用于**采样坐标**，不是高度。扭曲坐标出的是「山脊弯了」，扭曲高度出的是「山被抹糊了」。

```
p' = p + W · fBm₂oct( p / (0.3R) )          W = clamp(6%R, 4, 30) 格
```

### 第 2 步 · 山带遮蔽（决定「哪里有山」）

```
btype   = 陆陆 1.0 / 洋陆 0.8 / 洋洋 0.5 / 离散 0.15 / 转换 0.05
profile = exp( −(d / (0.5·W_belt))² )                      d = BoundaryDistance
segment = 0.4 + 0.6 · fBm₁D( 沿走向弧长 / (1.2·W_belt) )    // 0.4–1.0

mask    = btype · profile · segment
```

| 项 | 作用 | 漏掉会怎样 |
|---|---|---|
| `btype` | 哪些边界类型长山 | 7 块板块长 7 圈山，整颗星像橘子 |
| `profile` | 山带断面的高斯剖面 | 山带边缘是直角 |
| `segment` | 沿走向的分段（垭口、段高段低） | 山带是一条高度均匀的巧克力棒 |

`W_belt` = 造山带宽 = `clamp(3.2%R, 8, 32)` 格。

**离散边界和转换边界本来就几乎不长山**，这一条同时解释了为什么「每块板块都有自己的山」是错的。

### 第 3 步 · 多 octave ridged + 各向异性

```
h(p) = Σ_{k=0}^{N-1}  0.5^k · ridged( aniso(p') · 2^k / L0 )

ridged(x) = 1 − |noise(x)|
aniso    : 在山带局部坐标系 (s 沿走向, d 垂直走向) 中采样
           noise( s / (3·L0), d / L0 )        // 3:1 拉长，走向跟着边界走
L0       = 0.4R
N        = clamp(floor(log2(0.2R)), 2, 6)
```

`N` 必须随 `R` 变：`R=100` 时第 5 层的波长已小于 2 格，做了也看不见，白花求值预算。

| R | 100 | 250 | 500 | 1000 |
|---|---|---|---|---|
| octave `N` | 4 | 5 | 6 | 6（封顶） |

### 第 4 步 · 合成

```
ReliefRaw = mask · A_mtn · h(p)  +  (1 − mask) · A_plain · fBm₂oct(p')
```

| 参数 | 取值 | R=100 | R=500 | R=1000 |
|---|---|---|---|---|
| 山脉幅度 `A_mtn` | `clamp(1.2%R, 4, 12)` | 4 | 6 | 12 |
| 平原幅度 `A_plain` | `clamp(0.2%R, 0.5, 2)` | 0.5 | 1 | 2 |

`A_mtn` 是**单层**幅度，`h` 的 octave 求和后峰值约为 `2·A_mtn`，所以实际山高 ≈ `2·A_mtn`（R=500 时 12 格，陆台高度是 6 格，山顶海拔约 18 格）。

### 第 5 步 · 热力侵蚀

只做**坡度限制扩散**，不碰水。它只依赖高程，没有循环依赖——流水侵蚀需要降水（阶段 5），放在这里会和阶段 5 成环。

```
for i in 1..5:
    h(x) += λ · ( mean(neighbors) − h(x) )     仅在 slope(x) > tan(30°) 处生效
λ = 0.2
```

| | 本阶段（热力） | 阶段 6（流水） |
|---|---|---|
| 依赖 | 只要高程 | 高程 + 降水 |
| 作用 | 去棱角、出崩积坡、山前变缓 | V 形谷、冲积扇、河网 |
| 成本 | O(5N)，烘焙期可接受 | 见 `06-erosion.md` |

只加这一步的视觉收益就很高：ridged 噪声的尖刺被磨圆，立刻从「程序化地形」变成「像山的地形」。

**副作用**：热力侵蚀削低峰值，约损失 10–20% 的 `max(ReliefRaw)`。所以**值域必须按 `ReliefRaw` 估**，按 `ReliefDelta` 估会偏窄出洞。

## 海平面与半径

海平面固定在 `R₀`，由此产生三件必须同步的事：

| 事 | 说明 |
|---|---|
| **`R_max`** | `R₀ + A_up + 2·A_mtn`。大气层半径、水面高度、地表射线起点、相机 Far、LOD 边界凡是锚在半径上的，一律基于 `R_max`，不能写死 `R₀` |
| **海拔为负** | 水下高度是负值。任何 `Max(0, 高度)` / `Saturate(高度)` 的现有假设都会静默出错 |
| **`SeaLevelOffset`** | 全局参数，默认 0。阶段 6 靠它表达「这颗星水多 / 水少」，做海进海退。现在不实现，但接口先留 |

## 撒矿

本阶段**只撒一类**，其余全部后移。

| 矿 | 条件 | 形态 | 备注 |
|---|---|---|---|
| 蛇绿岩铬铁矿 | 缝合线上（`BoundaryType=3` 且 `CrustAge` 有突变） | 豆荚状透镜，成串 | 移到陆上的洋壳碎片，判据齐全 |
| ~~造山型金~~ | 需要剪切带 / 断层 | — | **移到 3B**；没有 3B 时不做 |
| ~~MVT 铅锌~~ | 需要碳酸盐层 | — | **移到 3A**；没有 3A 时不做 |

**为什么收窄**：本阶段手上只有高程、坡度、边界类型、岩性。硬要在这一层撒矿，很容易撒出「因为这里有山所以有金」——那是把随机换了个说法，正好回到要摆脱的东西。

阶段 3 的正确职责是**给后面的阶段提供有利部位**：哪里是山（`MountainMask`）、哪里坡度陡、哪里是盆地边缘。这些是阶段 4/6/7 的输入，不是撒矿的依据。

## 值域

| 层 | 值域来源 |
|---|---|
| `ElevationBase` | 阶段 2 的保守界（`≈ 3.2·A_up + amp`） |
| `ReliefDelta` | **按 `ReliefRaw` 估**：`2.2 · A_mtn`（山脉 + octave 细节 + 海沟） |

烘焙结束后**实测**全星 `Elevation` 的 min/max，用它反推生成器的上下界。估算偏窄会出洞，`PlanetTerrainEarlyOutTests` 就是为这条存在的。

注意：`ReliefRaw` 与 `ReliefDelta` 两个都要保底，因为热力侵蚀只削低不抬高，**按 `ReliefDelta` 的实测值去估会漏掉未被侵蚀削掉的极值点**。

## 分辨率现实

- 山脉高度至少 5 格，否则看不出是山。
- 海沟宽 `clamp(1.6%R, 4, 16)`；窄于 2 格就是一条缝，玩家会掉进去而不是「看到海沟」。
- 河谷最窄 2 格，再窄就用材质画深色表示。
- `N` 的最后一层波长 `L0/2^(N-1)` 必须 ≥ 2 格，否则那一层是纯浪费。

## 验收

1. **高程直方图呈三峰**：洋盆 −`A_down`、平原 `A_up`、山顶 `A_up + 2·A_mtn`。两峰说明山带遮蔽没生效，单峰说明阶地映射错了。
2. **山带覆盖率**：`area{mask > 0.5}` 落在 8–15%。低于 5% 是山太少（星球像土豆），高于 25% 是处处是山。
3. **山带数量**：主山带 3–6 条，不是「每条边界一条」。
4. **脊线检验**：沿山带垂直走向取 20 条剖面，`ReliefDelta` 的局部极大值应成线状（相邻剖面极大值位置连续），不是散点。
5. **热力侵蚀生效**：`max(ReliefDelta) < max(ReliefRaw)`，且比值落在 0.8–0.9；坡度直方图在 30° 附近有折点（阈值生效的证据）。
6. 球面无缝：极点与 cubemap 接缝处高程连续。
7. 与阶段 2 的 `BoundaryDistance` 对齐：海沟确实落在边界线上，山峰确实在火山弧距上。
8. **穿透一致性**：`M > 0.9`（大陆核心）处不应出现海沟型凹槽。
9. `R_max` 实测值写入全局参数，且与 `R₀ + A_up + max(ReliefDelta)` 一致。
