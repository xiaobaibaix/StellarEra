# 矿物描述文件

每个矿床一份 Markdown，不写进代码。规则引擎读「文件里的参数表」，程序读「元素映射」。
本目录的 README 是**索引 + schema**，单个矿的细节在同名文件里。

## 1. 文件格式

```markdown
# 矿名（英文名）
## 一句话           ← 玩家视角：在哪、能干什么
## 归属             ← 阶段 / 规则 Id / 优先级
## 条件             ← 谓词，逐条可勾
## 放置             ← 方式 + 参数
## 形态             ← 原语 + 尺寸 + 走向来源
## 品位             ← 刻度上限 + 峰值 + 剖面 + 规模
## 元素映射         ← 矿物 → 元素比例（产出用）
## 线索             ← 地表 / 围岩 / 仪器
## 参数表           ← 可直接填进 DataAsset 的默认值
## 验收             ← 怎么知道这个矿做对了
```

## 2. 三个量纲（**别混**）

| 量 | 含义 | 单位 | 存在哪 |
|---|---|---|---|
| 背景含量 | 这个地方本来有多少该元素 | ppm / % | 阶段 1 的 `Background` |
| 品位 | 这一个矿体有多富 | 每矿种自己的刻度 → 0–255 | 材质 `B` 通道 |
| 规模 | 一颗星上有几个、多大 | 每 km² 几个 / 格 | 规则的撒点参数 |

「密度含量」这种说法要避免——它同时指上面三个，导致规则永远调不准。

## 3. 品位刻度（必须逐矿定义）

`Grade8 = clamp(GradeReal / GradeMax) * 255`，各矿 `GradeMax` 不同：

| 矿种 | GradeMax | 说明 |
|---|---|---|
| 金 | 5 g/t | 超过 5 g/t 一律算满 |
| 铜 | 1% | |
| 铁 | 60% | |
| 硫 | 90% | |
| 锂 | 2000 ppm | |
| 金刚石 | 5 ct/100t | |
