# 硫磺（Sulfur）

## 一句话

**活火山口附近的亮黄色结壳。** 玩家飞过火山时最先看到的东西，也是「地表线索 → 地下矿」这条链的入口。

## 归属

| 项 | 值 |
|---|---|
| 阶段 | 4（岩浆活动） |
| 规则 Id | `sulfur_active_volcano` |
| 优先级 | 80（高于斑岩铜，因为它占据最表层） |
| 首次可做 | **S1 竖切**（火山点表可手填，不依赖板块与气候） |

## 条件

```
Volcano.bActive == true
AND WithinOf(Volcano.Crater, 4 格)
AND Depth ∈ [-1, +1]                 // 只在地表附近，不下探
```

**「活」只是点表属性**，不模拟熔岩、不做粒子。死火山（`bActive == false`）覆盖后**完全没有硫磺**——
这一条是可玩性的核心：玩家要学会分辨活火山与死火山（活的有喷气孔材质、死的长满风化色）。

## 放置

| 项 | 值 |
|---|---|
| 方式 | `AroundPrimitive`（以火山为锚） |
| 参考基元 | `Volcanoes` 中 `bActive` 的层状火山 / 破火山口 |
| 密度 | 每个活火山 1 簇，簇内 3–8 个斑块 |
| 分布 | 火口内壁 + 火口外 4 格内的喷气孔周围 |

## 形态

| 项 | 值 |
|---|---|
| 原语 | 层状（薄层）+ 团块（结壳斑块） |
| 结壳厚度 | 1 格（亚体素部分靠材质） |
| 斑块半径 | 1–2 格 |
| 噪声 | 高频（`ShapeDetail` 4–6），让结壳边缘碎 |

> 硫磺是「薄层 + 小斑块」，几何只有 1 格。**视觉主要靠材质**：亮黄 + 高粗糙度的结壳贴图。
> 这是分辨率预算下的正常取舍，不是妥协——真实硫磺结壳本来就薄。

## 品位

| 项 | 值 |
|---|---|
| 刻度上限 | S 90% |
| 峰值 | 60–90%（块状硫磺矿石在真实世界是 25–50%，风格化上调） |
| 剖面 | 结壳中心满值，边缘 `smoothstep` 衰减到 0 |
| 规模 | 单火山 3–8 簇 × 每簇 1–2 格 |

## 元素映射

```
S 1.0   → 产出「硫」
```
下游（留给工厂设计）：硫酸、火药、橡胶硫化。

| 档 | 线索 | 材质 |
|---|---|---|
| 远观 | 火山锥本身（阶段 4 的地形） | — |

## 参数表

| 参数 | 默认 | 说明 |
|---|---|---|
| `MaxDistanceFromCrater` | 4 格 | 超过就没有 |
| `ActiveOnly` | true | 死火山为零 |
| `PatchesPerVolcano` | 3–8 | 簇内斑块数 |
| `PatchRadius` | 1–2 格 | |
| `CrustThickness` | 1 格 | |
| `GradePeak` | 0.75 | 归一化到 S 90% |
| `ClueStrength` | 15（满） | 最容易读的线索 |
| `Reliability` | 1.0 | 看见硫磺就一定有硫磺 |

## 验收

1. **反例测试**：把所有火山设为 `bActive=false`，全星硫磺体素数必须为 0。
2. **正例测试**：每个活火山 4 格内至少 1 个体素 `Mineral == 硫磺`。
3. 边界测试：距火口 5 格处必须为 0（不出现泄漏）。
4. 视觉：飞到任意活火山，肉眼能看出黄色结壳，不需要仪器。
