# 浅成低温金银（Epithermal Au-Ag）

## 一句话

**火山锥下面 2–6 格的脉状金银。** 是「硫磺 → 金银 → 斑岩铜」这根竖直矿柱的中间一段。

## 归属

| 项 | 值 |
|---|---|
| 阶段 | 4 |
| 规则 Id | `epithermal_au_ag_arc` |
| 优先级 | 60 |

## 条件

```
Volcano.bActive == true OR Volcano.Age < 0.3
AND Depth ∈ [2, 6]                    // 锥顶面以下 2–6 格
AND DistanceFromConduit < 4 格        // 火山通道附近
```

老火山被剥蚀掉锥顶后，这一段会**出露到地表**——这正是「剥蚀改变出露」的体现（阶段 6 的 `ErosionDepth` 参与判定）。

## 放置

| 项 | 值 |
|---|---|
| 方式 | `AroundPrimitive`（火山通道） |
| 数量 | 每个火山 1 组脉，2–5 条 |
| 走向 | 放射状，围绕通道向外倾 |

## 形态

| 项 | 值 |
|---|---|
| 原语 | 线状带 |
| 长 | 6–12 格 |
| 宽 | 1–2 格 |
| 衰减 | 沿走向衰减 0.5，末端 `smoothstep` 收口 |

## 品位

| 项 | 值 |
|---|---|
| 刻度上限 | Au 30 g/t |
| 峰值 | 8–25 g/t（真实浅成低温是数到数十 g/t） |
| 副产 | Ag 3–10 倍于 Au 的摩尔量 → 写 `U0/V0` |
| 剖面 | 脉中心满值，横向 `smoothstep` 到 0 |

## 元素映射

```
Au 1.0  → 产出「金」
Ag 1.0  → 产出「银」（次要矿物通道）
```

## 线索

| 档 | 线索 |
|---|---|
| 近看 | 硅化（灰白硬壳）、明矾石（浅粉）、玉髓（蜡状） |
| 近看 | 老火山锥顶被削平 + 顶部脉露头 |
| 仪器 | 元素扫描仪读 Au（范围极小，容易被漏掉） |
| 挖掘 | 挖到 2 格深出现石英脉 |

**Reliability < 1**：只有一部分脉含金（按 `Age` 与 `bActive` 调），不是每条都有。

## 参数表

| 参数 | 默认 |
|---|---|
| `DepthMin` / `DepthMax` | 2 / 6 格 |
| `VeinsPerVolcano` | 2–5 |
| `VeinLength` | 6–12 格 |
| `VeinWidth` | 1–2 格 |
| `GradePeak` | 0.7（归一化到 30 g/t） |
| `AgToAuRatio` | 5 |
| `Reliability` | 0.6 |

## 验收

1. 竖直采样：硫磺(0 格) → 金银(2–6 格) → 斑岩铜(6–15 格)，顺序不可颠倒。
2. 剥蚀测试：把 `ErosionDepth` 调到大于锥高，金银必须出露到地表。
3. 脉的走向确实呈放射状（夹角分布均匀）。
