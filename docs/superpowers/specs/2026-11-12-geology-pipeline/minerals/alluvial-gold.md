# 砂金（Alluvial Gold）

## 一句话

**干河谷底的金色重砂。** 上游有原生金，水流把它磨碎带到下游，在变缓的地方沉下来。
玩家顺着河谷往上游走，金砂越来越多，然后突然断了——原生金脉就在那一段两侧的山里。

## 归属

| 项 | 值 |
|---|---|
| 阶段 | 6（侵蚀与沉积） |
| 规则 Id | `placer_gold_fluvial` |
| 优先级 | 70 |
| 首次可做 | S3 竖切 |

## 条件

```
UpstreamHas(Mineral == 原生金, Distance < 40 格)   // 必须有源
AND FlowAccum > 阈值                                // 水量不够冲不动
AND ReliefType ∈ {丘陵, 高山}                        // 平原沉积的是细粒，不是重砂
```

**「无源不砂矿」是硬规则。** 上游 40 格内没有原生金（阶段 4 的金银脉 / 斑岩铜的伴生金），砂金强度恒 0。
这条是整个玩法的支点：玩家挖到砂金，就知道上游一定有源。

## 放置

| 项 | 值 |
|---|---|
| 方式 | `InField`（沿流路撒） |
| 载体 | 阶段 6 的 `Valley`（中心线 + 宽度 + 汇流量） |
| 沉积点 | 优先权重（见下表） |

| 沉积位置 | 权重 | 理由 |
|---|---|---|
| 曲流凸岸 | 1.0 | 流速最慢 |
| 急流下方 | 0.8 | 突然减速 |
| 冲积扇顶 | 0.7 | 出山即散 |
| 古河道底（贴基岩） | 1.2 | 最富 |
| 河漫滩 | 0.3 | 细粒，品位低 |

## 形态

| 项 | 值 |
|---|---|
| 原语 | 沿流程衰减 + 薄层 |
| 厚度 | **1 格**（几何只此一层，视觉靠材质） |
| 横向 | 谷底宽度的 60–80% |
| 衰减 | `exp(-k · 流程距离)`，`k` 由 `FlowAccum` 反比调节（水大衰减慢） |

## 品位

| 项 | 值 |
|---|---|
| 刻度上限 | Au 1 g/t（砂矿刻度与岩金不同，**必须独立**） |
| 峰值 | 0.1–1 g/t（真实砂矿 0.1–1 g/t 即可采） |
| 剖面 | 沿流单调不增；沉积点处跳升 1.5–2× |
| 规模 | 单条谷 20–60 格长 × 1 格厚 |

## 元素映射

```
Au 1.0  → 产出「金」（与岩金共用资源）
副产：磁铁矿、钛铁矿、锆石 → 重砂（可选，写 `U0/V0`）
```

## 线索

| 档 | 线索 |
|---|---|
| 远观 | 无（砂矿太小） |
| 近看 | **谷底深色/金色条带**（`ClueType = 重砂`） |
| 近看 | 干河谷（无水，见 `§2.6` 液体约定） |
| 仪器 | 元素扫描仪读 Au（范围极小，必须贴着谷底走） |
| 挖掘 | 挖开 1 格就到底岩，砂层之下直接是基岩 |

**这是「读线索找矿」的教科书例子**：看到谷底颜色 → 沿谷往上游取样 → 品位升高 → 突然断 → 两侧找脉。

## 参数表

| 参数 | 默认 |
|---|---|
| `SourceSearchRadius` | 40 格 |
| `MinFlowAccum` | 阈值（按 R 标定，先取 90 分位） |
| `DecayK` | 0.02 / 格（流水大时减半） |
| `LayerThickness` | 1 格 |
| `GradePeak` | 0.5（归一化到 1 g/t） |
| `DepositWeights` | 见上表 |
| `Reliability` | 1.0（有砂就上游有源，这是玩法承诺） |

## 验收

1. **单调性**：沿任意流路从上游到下游采样 100 点，品位必须单调不增（允许沉积点处局部跳升）。
2. **无源性**：删掉上游所有原生金矿体后，该流域砂金必须全部为 0。
3. **断点**：品位归零处，上游 8–20 格内必然存在原生金矿体。
4. **厚度**：任何砂金体素的垂直厚度 ≤ 1 格（不能变成整层矿）。
