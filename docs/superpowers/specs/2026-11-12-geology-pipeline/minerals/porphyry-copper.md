# 斑岩铜（Porphyry Cu-Mo-Au）

## 一句话

**弧火山下面 6–15 格的大型浸染状矿体。** 地表的硫磺和蚀变色是它的招牌线索，也是最经典的「找矿」教学案例。

## 归属

| 项 | 值 |
|---|---|
| 阶段 | 4 |
| 规则 Id | `porphyry_cu_arc` |
| 优先级 | 40（低于金银，因为它更深、更大） |

## 条件

```
BoundaryType ∈ {汇聚-洋陆, 汇聚-洋洋}
AND Intrusion.Type == 岩株
AND Depth ∈ [6, 15]                   // 锥顶面以下
AND Intrusion.CrustTypeAround == 陆壳  // 陆弧偏 Cu-Mo，洋弧偏 Cu-Au
```

## 放置

| 项 | 值 |
|---|---|
| 方式 | `AroundPrimitive`（岩株） |
| 参考基元 | `Intrusions` 中类型为岩株的实例（岩基顶部伸出的小团块） |
| 数量 | 每个岩株 1 个矿体 |
| 密度 | 每条弧每 2–3 个火山有 1 个经济价值的斑岩 |

## 形态

| 项 | 值 |
|---|---|
| 原语 | 团块（三轴不等椭球，软边） |
| 宽 | 4 格（**分辨率下限**，真实是 1–2 km） |
| 高 | 3 格 |
| `Hard` | 0.2（软边，浸染状无硬边界） |
| 噪声 | 中频，让品位斑驳 |

> **4 格宽意味着「能挖到、能看出轮廓，但看不出精细分带」**。所以蚀变分带不做几何，只做材质。

## 品位

| 项 | 值 |
|---|---|
| 刻度上限 | Cu 1% |
| 峰值 | 0.5–0.9%（真实 0.3–1%） |
| 剖面 | 中心满值，向外 `smoothstep` 到 0.1，边缘低于边界品位 |
| 副产 | Mo（陆弧）或 Au（洋弧），写 `U0/V0` |
| 规模 | 单矿体 4×4×3 ≈ 48 格 |

## 元素映射

```
Cu 1.0  → 产出「铜」
Mo 1.0  → 产出「钼」（陆弧）
Au 1.0  → 产出「金」（洋弧，与金银矿共用资源）
```

## 线索（本矿的核心）

**蚀变同心分带**，从内到外四级，全部走材质 `A` 通道：

| 环 | 距岩株中心 | `ClueType` | 材质表现 |
|---|---|---|---|
| 钾化 | 0–1 格 | 钾化 | 粉红/肉红，黑云母 |
| 绢英岩化 | 1–2 格 | 绢英岩 | 灰白，细粒 |
| 泥化 | 2–3 格 | 泥化 | 漂白 + 黄褐 |
| 青磐岩化 | 3–4 格 | 青磐岩 | 绿（绿泥石/绿帘石） |

地表表现：**黄白色斑块**（远观可见），配合硫磺与喷气孔。

| 档 | 线索 |
|---|---|
| 远观 | 黄白色蚀变斑块（线索 cubemap） |
| 近看 | 蚀变环逐圈变色；铁帽（若有硫化物） |
| 仪器 | 元素扫描仪读 Cu（范围小、深度浅，只能看到顶部） |
| 挖掘 | **往下挖：先漂白 → 再变色 → 出现钾化 → 进入矿体** |

挖掘中看到的「逐圈变色」是 4 段 `ClueType` 的切换，不是几何形状。

## 参数表

| 参数 | 默认 |
|---|---|
| `DepthMin` / `DepthMax` | 6 / 15 格 |
| `BodyRadiusXY` | 2 格（直径 4） |
| `BodyRadiusZ` | 1.5 格 |
| `GradePeak` | 0.7（归一化到 1%） |
| `CuMoRatio` | 陆弧 50:1，洋弧 0 |
| `AlterationRings` | 4 环，半径 1/2/3/4 |
| `ClueStrength` | 10–12 |

## 验收

1. 竖直采样：从火山顶往下，命中顺序 硫磺 → 金银 → 斑岩铜，且斑岩铜在 6–15 格区间内。
2. 蚀变环：从中心向外采样，`ClueType` 必须按 钾化 → 绢英岩 → 泥化 → 青磐岩 单调切换。
3. 陆弧/洋弧副产不同：陆弧有 Mo 无 Au，洋弧有 Au 无 Mo。
4. 剥蚀测试：剥掉 10 格后，钾化带直接出露地表。
