# 阶段 7：表生风化

> 类型：2D 厚度 + 逐体素细节 / 改密度：**薄层修饰** / 撒矿：铝土、红土镍、次生铜、铁帽、高岭土
> 最小可辨：风化壳 ≥ 2 格（实际主要靠材质）

## 职责

在最外面盖一层「被雨和温度改造过的皮」。它产出**最多的地表线索**（铁帽、红土色、蚀变色），
所以是阶段 6 之后、玩家最先看到的东西。

## 输入

| 键 | 来源 |
|---|---|
| `Temperature` `Precipitation` `Biome` | 5 |
| `Elevation`（坡度） | 3 |
| `ErosionDepth` | 6 |
| 岩性（3A 或 4） | 3A / 4 |

## 输出

| 键 | 说明 |
|---|---|
| `WeatheringDepth` | 风化壳厚度（体素） |
| `SoilType` | 土壤 / 风化产物类型 |

## 逻辑

```
depth = f(Precipitation, Temperature) × (1 - slope) × 暴露时间
```
- 湿热 + 平缓 + 长期暴露 → 最厚（数 10 格，按比例缩）
- 沙漠、陡坡 → ≈ 0
- 剖面从上到下：铁质硬壳 → 斑杂带 → 腐岩 → 新鲜基岩（核心「核石」用噪声球残留）

## 撒矿

| 矿 | 条件 | 形态 |
|---|---|---|
| 红土型铝土矿 | 湿热 + 排水好的平缓台地 + 富铝母岩 | 近地表毯状层 |
| 红土型镍 | 湿热 + 超镁铁母岩（蛇绿岩，阶段 3） | 毯状层 |
| 次生富集铜 | 斑岩铜（4）上方、固定深度近似潜水面 | 淋滤帽下的富集毯 |
| 铁帽 | 硫化物矿体露头 | 地表红褐斑块（本身价值低，是线索） |
| 高岭土 | 花岗岩风化 | 风化壳中 |

## 分辨率现实

- 风化壳在 R=500 时约 2–10 格，**几何意义有限，主要意义是材质**。
- 「核石」是亚体素特征，不做几何，用材质噪声代替。
- 特色地貌（沙丘、喀斯特漏斗）比矿更依赖几何，建议单独评估，不要塞进本阶段。

## 验收

1. 湿热平缓处风化壳最厚，陡坡与沙漠 ≈ 0。
2. 次生铜必须在斑岩铜正上方且不超出其水平范围。
3. 铁帽只在硫化物矿体露头处出现，且**剥蚀到矿体**才出现（未出露则没有）。
4. 线索与阶段 4/6 的矿体一一对应（不出现「有铁帽没矿体」的孤立线索，除非是故意的难度旋钮）。
