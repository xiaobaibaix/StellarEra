# 材质场契约

## 1. 插件给什么（已核对源码）

`VoxelMaterial.h:438-477` + `VoxelDefinitions.h:161-185`：

- 默认 8 个 8 位通道：`R G B A U0 V0 U1 V1`（`UV2`/`UV3` 默认关，插件勿改）。
- 三种配置（`EVoxelMaterialConfig`）：`RGB` / `SingleIndex` / `MultiIndex`。
- 现状项目用 `RGB`，只存了颜色。

## 2. 通道布局（RGB 配置）

| 通道 | 含义 | 来源阶段 |
|---|---|---|
| `R` | 岩性索引 0–255 | 1 / 3A / 4 / 7 |
| `G` | 主矿物索引 0–255 | 2 / 4 / 6 / 7 |
| `B` | 主矿品位 0–255（**按矿种自己的刻度**） | 同上 |
| `A` | 线索类型（高 4 位=16 种）+ 强度（低 4 位=16 档） | 4 / 6 / 7 |
| `U0` | 次矿物索引 | 4（共生矿） |
| `V0` | 次矿品位 0–255 | 4 |
| `U1` / `V1` | 预留：湿度 / 群系 / 仪器标记 | 5 |

容量：岩性 30–50 种、矿物 30–60 种，都在 256 内。

## 3. 索引插值（本方案最关键的一个坑）

顶点属性在三角形内线性插值。两个顶点岩性索引 5 和 9 之间会插出 7 ——**一个不存在的岩性**。

### 解法：索引相邻规则（推荐，成本最低）

**把相近岩性编成相邻编号**，让插值误差落在同类里：

```
0-19   火成（花岗岩、闪长岩、辉长岩、玄武岩…按成分渐变排）
20-39  沉积（砾岩→砂岩→页岩→石灰岩→蒸发岩，按粒度/成分渐变排）
40-59  变质（板岩→片岩→片麻岩→大理岩→石英岩）
60-79  风化产物
80-99  深部（橄榄岩、高压相、地核）
```

这样「花岗岩(5) 与 闪长岩(7) 的交界」插出 6，仍然是火成岩的某个合理成员，视觉上只是成分过渡。
而「花岗岩(5) 与 石灰岩(25)」的交界在几何上是**硬接触**，插值区间会跨越大类 —— 这种情况由 shader 取整解决：

```hlsl
float idx = floor(R * 255.0 + 0.5);   // 取最近，不插值
```
硬切正好符合「侵入体与围岩是硬接触」的地质事实。**渐变岩性不做**，靠贴图噪声表现。

### 备选：`MultiIndex`（会吃掉整个布局）

`VoxelMaterial.h:77-92`：

```
MultiIndex_Blend0/1/2 = R G B        ← 变成 3 个混合权重
MultiIndex_Wetness    = A            ← 变成湿度
MultiIndex_Index0..3  = U0 V0 U1 V1  ← 只剩 4 个索引
```

用了它就没有「品位、线索类型+强度、次矿物」的位置。**阶段 0 必须把这个 trade-off 写进验收标准**，
不要先验证「MultiIndex 插值正确」再发现布局要推倒。

## 4. 粗 LOD 聚合

粗 LOD 下一个体素代表很大体积，点采样会让线索随相机移动闪烁。

| 项 | 粗 LOD 规则 |
|---|---|
| 岩性 | 取烘焙期的二维「主导岩性图」的**地表值**（不下探，粗 LOD 只在远处用） |
| 矿物 / 品位 | **不显示**（玩家在远处看不到具体矿） |
| 线索 | 取「区域内最强线索」，来自线索 cubemap |

阈值 LOD 可配。判断在 `GetMaterialImpl` 里用 LOD 参数做，不要在外面绕。

## 5. 编解码只允许一处

```
FGeoSample { Density, Lithology, Mineral, Grade, SecondaryMineral, SecondaryGrade, Clue, ClueStrength }
      │  FGeoMaterialCodec（全项目唯一）
      ▼
FVoxelMaterial
```

- 体素适配器**编码**，shader 与找矿查询**解码**。
- 以后换布局或换 `MultiIndex` 只改这一个类 + 一个材质函数 `MF_GeoDecode`。
- 两边必须同源：编码器的通道表用代码生成 shader 常量，别手抄。

## 6. shader 侧要点

- `MF_GeoDecode`：从顶点色与 UV 解出 8 个字段，与编码器同一份布局。
- 岩性 → `Texture2DArray` 层号，三平面映射。
- 矿物按品位控制覆盖度叠在岩性上。
- 线索（蚀变色、铁帽、盐壳、硫磺黄）作为颜色 + 粗糙度的调制层，按强度混合。
- 远处直接采样线索 cubemap，与近处按距离淡入淡出。

## 7. 验收

1. 编码→解码往返一致（255 个索引 × 256 个品位全枚举）。
2. 三角形跨两大类岩性时，shader 取整后只出现两端之一，**不出现中间值**。
3. 同类岩性相邻时，过渡看起来是成分渐变而非硬切。
4. 粗 LOD 下相机移动 10 秒，线索不闪烁。
