# 瞬时引力主导剖分（可视化）设计

**日期**：2026-10-20
**状态**：已在会话内确认（用户选择「瞬时引力主导剖分」）
**实施计划**：`docs/superpowers/plans/2026-10-20-dominance-partition.md`

## 1. 问题

希尔球 `r_H = a·(m/3M)^(1/3)` 只在小质量比、分级系统中成立。用户需要一个能覆盖
**三颗质量相当的天体**的可视化：在那种系统里，希尔球没有定义（公式退化、没有
稳定的闭合归属边界）。

## 2. 定义

对天体 i，定义其**瞬时引力主导区**：

```
R_i = { P : m_i / |P - r_i|² ≥ m_j / |P - r_j|²  对所有 j ≠ i }
```

这是字面意义的「这块空间此刻谁的引力最强」。对任意天体数、任意质量都有精确定义。

两体 i、j 的边界：

```
|P - r_i| / |P - r_j| = sqrt(m_i / m_j)
```

该轨迹在空间中是 **Apollonius 球**；`m_i == m_j` 时退化为**中垂面**。
球心与半径：

```
k = sqrt(m_i / m_j)
球心 C = (r_i - k² r_j) / (1 - k²)
半径 R = k |r_i - r_j| / |1 - k²|
```

## 3. 它不是什么

- **不是希尔球**：不含旋转系的离心/潮汐项。对本关卡行星，希尔球 1.54 AU，
  而纯引力主导球约 0.47 AU（差约 3.3 倍）。两者回答不同问题，并存，不互相替代。
- **不是动力学稳定区**：不回答「小物体长期会不会留在它身边」。三体全质量系统中
  长期归属没有空间边界，只能靠数值积分的捕获盆地/稳定图（本设计不做）。
- 边界随天体位置**连续**变化（逐帧重算），不是混沌跳变；混沌在相空间，不在这里。

## 4. 渲染方案

复用 `UCosmosTrajectoryComponent` 已有的行批、星图门控与编辑器离线路径：

1. 收集本关卡所有 `bExertsGravity` 的 `UCosmosOrbitComponent`（世界坐标 + MassEarth）。
2. 对每一对天体计算 Apollonius 球/平面。
3. 在球面（经纬网格）或平面（正交网格）上采样，点必须同时满足：
   - 在裁剪球内（最重天体的主导区无界，`DominanceClipRadiusCm` 默认 150 AU）；
   - **该对是此刻最强的两颗**（其余天体在该点都不更强）。
4. 连接相邻的保留点，形成裁剪后的线框 patch。
5. 每对只由**较重**的一方绘制；等重按 Actor 名排序。双方都开也不会重复，
   且任一方单独开启即可画出它参与的边界。
6. 运行期挂在星图门控下；编辑器态随 `bShowInEditor` 走离线路径。

## 5. 参数

| 属性 | 默认 | 含义 |
|---|---|---|
| `bDrawDominancePartition` | false | 总开关（系统级） |
| `DominanceColor` | (150,190,255) | 网格颜色 |
| `DominanceClipRadiusCm` | 1.5e8（150 AU） | 无界区域裁剪半径 |
| `DominanceSphereSegments` | 32 | 球面经向段数 |
| `DominanceSphereRings` | 8 | 球面纬向圈数（不含两极） |
| `DominancePlaneSegments` | 32 | 平面每方向格数 |
| `MinDominanceRadiusCm` | 100 | 球面半径小于此值不画（飞船等微小区域） |

## 6. 验收

- 纯函数单测：等质量→平面、球心/半径、边界引力相等、第三体裁剪、无效输入。
- 集成测试：恒星组件画出 patch、较轻一方不重复、连续 Tick 不累加。
- `StellarEraEditor Win64 Development` 构建通过；`StellarEra` 自动化全绿。

## 7. 不做

- 数值稳定图 / 捕获盆地（预计算、非实时）。
- 旋转系有效势（Jacobi）剖分——只对无质量探针有意义，无法描述三个大天体自身。
