# 大尺度渲染映射（2026-11-22）

## 目标

仿真层继续跑真实物理尺度（AU、秒、真实质量距离），引擎只看到经过相似映射的**表现空间**：近场 1:1，远场统一压缩。为将来的时间缩放留出边界，本期不实现时间缩放。

## 分层与边界

| 层 | 内容 | 规则 |
|---|---|---|
| 仿真层 | `FNBodySimulator` + `UCosmosSimulationSubsystem`，AU / 秒 | 唯一真源，不读引擎世界坐标 |
| 映射层 | 纯函数、无 UObject、无状态：`FUniverseMapping::ToRender` / `ToSim` | 不读 dt、不积分、不积累状态 |
| 表现层 | Actor 变换与缩放、灯光方向、材质参数 | 只读映射输出 |

硬约束：除映射层外不许把仿真坐标直接当世界坐标使用；引擎侧写回仿真的量（推力、接触、射线）必须走 `ToSim`。

## 映射定义

锚点 = 飞船，不是星心：星心会让远场方向产生约 `R_body / (k·d)` 的偏差（1 AU、10 km 行星、k=1e-6 时约 3.8°）。

- 当前天体：`P = ship + (P_sim − ship_sim)`，`scale = 1`。
- 其余天体：`P = ship + (P_sim − ship_sim) × k`，`scale = k`。
- 方向不变，角直径严格守恒：`k·r / k·d = r/d`。

### 两套标定（前置前提）

项目现在的 `CentimetersPerAu = 1e6` 把仿真长度和世界长度绑在一起（1 AU = 10 km，行星在仿真里半径是 1 AU）。本设计要拆开：

- `PhysicalCmPerAu = 1.496e13`：仿真/物理换算用，行星半径在仿真里回到真实的 `6.7e-8 AU`。
- `RenderCmPerAu = 1e6`：表现空间标定，保持现有观感（1 AU → 10 km）。
- 远场比例 `k = RenderCmPerAu / PhysicalCmPerAu ≈ 6.68e-8`：1 AU → 1e6 cm（10 km），10 km 行星 → 0.67 mm，太阳 → 47 m。远场整体落在 1e6 cm 内。

## 切换规则

- 当前天体 = 距飞船最近、且真实距离小于 `R_near` 的天体；其它天体全部走远场。
- `R_near = D_min / k`（`D_min` 为远场最小可渲染距离，约 1 km）：约 `1.5e12 cm` = `1.5e7 km` ≈ `0.1 AU`。
- 切换时位置偏移与半径同时乘 `1/k`，相似变换保持从飞船出发的每条射线，**屏幕逐像素不变**，不需要淡入。跳变的只有世界坐标与远场互遮挡，此时目标屏幕尺寸很小，不可见。
- 进出带滞回（进 `R_near`、出 `2·R_near`），防止边界抖动。

## 天体表示

- **数据**：所有天体体素世界常驻，切换时不重烘、不重建（已确认的选择）。
- **渲染**：远场用廉价代理（角直径正确的球/广告牌，无碰撞）；当前天体用体素网格；切换时两者角直径相同，无跳变。
- 理由：k 缩放下远场体素网格的世界距离只有厘米～米级，LOD、区块划分、近裁剪、碰撞都会失控。

## 前置修复（必须先做）

1. 仿真长度标定改为 `PhysicalCmPerAu`：半径、接触探针、`ToWorldGameUnits` 一类换算都用物理值；表现层坐标只由映射产出。这一步与写回切换分开做，先保证仿真侧自洽。
2. 把 Actor 缩放从以下链路摘掉，一律只用**未缩放** `Radius`：

- `AVoxelPlanetActor::ComputeParamsHash`
- 生成器输入 `ToConfig(GetScaledRadiusVoxels())`
- `ComputeOrbitLOD` 与 `RefreshLODInvoker` 的 `RangeSource`
- 烘焙缓存键（半径字段）
- `SetWorldSize`

摘掉后验证 `GetSurfaceRadiusCm()` 与网格世界半径的 `Radius·S²` / `Radius·S` 矛盾消失。

## 时间缩放预留

- 映射无状态、不读 dt，仿真时间与表现时间分离。
- 将来只改求解器步长/时间倍率，映射与渲染层不动。
- 近地表禁止物理加速属于将来的限制，本期不实现，只保留参数位。

## 测试

1. 往返：`ToSim(ToRender(x)) == x`。
2. 近场恒等：当前天体 `scale = 1`，位置等于真实偏移。
3. 切换不变式：切换前后同一画面点的方向与角直径相等。
4. 无状态：同一输入两次调用结果相同。
5. 边界：`k·d < D_min` 时不切换，切换只在阈值外发生。

## 取舍

- 映射不是全局刚性：锚点切换时远场天体之间的相对几何会变；近场与远场不共面。这是方案的固有代价，切换点选在目标屏幕尺寸小时不可见。
- 收益：仿真零改动；精度问题消失（近场限制在星体半径内，远场限制在 150 km 内）。
- 风险：读绝对世界坐标的材质（大气/云）参数需按 s 换算；附着物会继承缩放；物理半径必须保持真实值，否则出现看不见的碰撞面。

## 不在本期

- 时间缩放的实现。
- 远场代理的具体资产与 LOD 策略（实现期确定）。
- 任意天体的按需体素生成（本期全部常驻）。

## Milestone 3 硬性要求（物理半径 tripwire）

M2 只做动态渲染原点，不含本项。

- M3 必须把 `CosmosSimulationSubsystem`、`CosmosTrajectoryComponent`、`StarMapUISystem` 里的物理半径读取改成未缩放值（`Radius·VoxelSize / PhysicalCmPerAu`）；`GetSurfaceRadiusCm()` 只作渲染空间使用，**不得**喂给求解器。
