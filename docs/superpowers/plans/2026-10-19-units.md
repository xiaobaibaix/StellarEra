# N 体单位统一 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 N 体输入边界统一成「质量 M⊕、速度 km/s、距离/软化 AU、时间 年」，换算集中到 `CosmosUnits`，旧资产经 `PostLoad` 无损迁移，并在编辑器里直接回显 AU / km/s / M☉。

**Architecture:** 四层单位契约：设计层（编辑器手填 M⊕/km/s）、求解器层（Core 内部 M☉/AU/AU每年）、世界层（UE 厘米/秒）、换算层（只允许 `CosmosTypes.h` 的 `CosmosUnits::`）。`UCosmosOrbitComponent` 只存参数并加一个**纯显示 Tick**刷新只读回显；物理推进仍只由 `UCosmosSimulationSubsystem` 驱动。旧字段保留序列化，`PostLoad` 幂等迁移后清零，代码不再消费。

**Tech Stack:** Unreal Engine 5.8.3 / C++ / 双精度 `FVector3d` / 自带 Automation Test 框架 / VoxelFree（不改）。

**Spec:** `docs/superpowers/specs/2026-10-19-units-design.md`

**本计划的单位契约（spec §3）**

- 设计层：质量 **M⊕**、速度 **km/s（物理速度）**、距离/软化 **AU**、时间 **年**。
- 求解器层：`FNBodySimulator` 内部仍是 **M☉ / AU / AU每年 / AU每年²**，本轮不改。
- 世界层：UE 仍是**厘米 / 秒**；`CentimetersPerAu` 与 `TimeScale` **不改值**。
- 换算只允许走 `CosmosUnits::`；调用点禁止手写 `× CentimetersPerAu × TimeScale`。
- **物理速度 ≠ 世界速度**：1 AU/年 = 4.740470463533348 km/s = `CentimetersPerAu × TimeScale` 厘米/秒（默认 3330 cm/s）。编辑器初速是物理速度，HUD 显示世界速度。

**照抄的数值（不要重算、不要换数字）**

| 量 | 值 |
|---|---|
| `AuToKilometer` | 1.495978707e8 |
| `KilometerPerSecondPerAuPerYear` | 4.740470463533348 |
| `AuPerYearPerKilometerPerSecond` | 0.21094952656969873 |
| `SolarMassInEarthMasses` | 332946.0837433315 |

在 `CosmosTypes.h` 的 `namespace CosmosUnits` 内、`EarthOrbitalSpeed` 之后追加：

```cpp
	// ── 人类单位 ↔ 求解器单位 ────────────────────────────────────────
	//
	// 设计层（编辑器里手填）用 M⊕ / km/s；求解器内部仍是 M☉ / AU / AU每年。
	// 换算只允许出现在这里。常量与函数刻意不同名：常量是比率，函数是变换。

	/** 1 千米 = 1e5 厘米。HUD 与飞船模块都用它，避免散落魔数。 */
	inline constexpr double CentimetersPerKilometer = 1.0e5;

	/** 1 AU = 1.495978707e8 公里。 */
	inline constexpr double AuToKilometer = AuToCentimeter / CentimetersPerKilometer;

	/** 1 AU/年 = 4.740470463533348 km/s（物理速度）。 */
	inline constexpr double KilometerPerSecondPerAuPerYear =
		AuToKilometer / YearToSecond;

	/** 1 km/s = 0.21094952656969873 AU/年。 */
	inline constexpr double AuPerYearPerKilometerPerSecond =
		1.0 / KilometerPerSecondPerAuPerYear;

	/** 1 M☉ = 332946.0837433315 M⊕。 */
	inline constexpr double SolarMassInEarthMasses = 1.0 / EarthMass;

	/** 质量：地球质量 → 太阳质量（求解器单位）。 */
	inline double EarthMassToSolarMass(double MassEarth)
	{
		return MassEarth * EarthMass;
	}

	/** 质量：太阳质量 → 地球质量（设计层单位）。 */
	inline double SolarMassToEarthMass(double MassSolar)
	{
		return MassSolar * SolarMassInEarthMasses;
	}

	/** 速度：AU/年 → km/s（物理速度）。 */
	inline FVector3d AuPerYearToKilometerPerSecond(const FVector3d& Velocity)
	{
		return Velocity * KilometerPerSecondPerAuPerYear;
	}

	/** 速度：km/s → AU/年（求解器单位）。 */
	inline FVector3d KilometerPerSecondToAuPerYear(const FVector3d& Velocity)
	{
		return Velocity * AuPerYearPerKilometerPerSecond;
	}

	/** 速度：求解器 AU/年 → 世界厘米/秒（含游戏时钟）。标定无效时返回 0。 */
	inline double GameVelocityToWorldCmPerSecond(double Velocity, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale;
		return Scale > 0.0 ? Velocity * Scale : 0.0;
	}

	/** 速度：世界厘米/秒 → 求解器 AU/年。标定无效时返回 0。 */
	inline double WorldCmPerSecondToGameVelocity(double Velocity, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale;
		return Scale > 0.0 ? Velocity / Scale : 0.0;
	}

	/** 加速度：求解器 AU/年² → 世界厘米/秒²（含游戏时钟）。标定无效时返回 0。 */
	inline double GameAccelerationToWorldCmPerS2(double Acceleration, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale * TimeScale;
		return Scale > 0.0 ? Acceleration * Scale : 0.0;
	}

	/** 加速度：世界厘米/秒² → 求解器 AU/年²。标定无效时返回 0。 */
	inline double WorldCmPerS2ToGameAcceleration(double Acceleration, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale * TimeScale;
		return Scale > 0.0 ? Acceleration / Scale : 0.0;
	}

	// ── 向量重载：调用点传整条速度/加速度，不再自己乘标定值 ──

	inline FVector3d GameVelocityToWorldCmPerSecond(
		const FVector3d& Velocity, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale;
		return Scale > 0.0 ? Velocity * Scale : FVector3d::ZeroVector;
	}

	inline FVector3d WorldCmPerSecondToGameVelocity(
		const FVector3d& Velocity, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale;
		return Scale > 0.0 ? Velocity / Scale : FVector3d::ZeroVector;
	}

	inline FVector3d GameAccelerationToWorldCmPerS2(
		const FVector3d& Acceleration, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale * TimeScale;
		return Scale > 0.0 ? Acceleration * Scale : FVector3d::ZeroVector;
	}

	inline FVector3d WorldCmPerS2ToGameAcceleration(
		const FVector3d& Acceleration, double CmPerAu, double TimeScale)
	{
		const double Scale = CmPerAu * TimeScale * TimeScale;
		return Scale > 0.0 ? Acceleration / Scale : FVector3d::ZeroVector;
	}
```

```cpp
	/**
	 * 质量，单位 **地球质量 M⊕**（1 M⊕ = 3.0034893e-6 M☉）。默认 1 = 地球。
	 *
	 * 行星之间的引力相对恒星可以忽略，但质量仍是决定「谁绕谁」的唯一依据 ——
	 * 中心天体必须是这里面最大的那个，否则行星会直接飞出去。
	 *
	 * 单位换算：1 M☉ = 332946.0837 M⊕。中心恒星填 10000 M☉ 就是
	 * 3.329460837e9 M⊕；只读回显 MassSolarReadout 会把它折回 M☉。
	 * 必须 > 0；<= 0（含 NaN）的天体在注册时会被跳过并报错。
	 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Cosmos|Body",
		meta = (DisplayName = "质量（地球质量 M⊕）"))
	double MassEarth = 1.0;

	/**
	 * 是否作为**引力源**吸引其他天体。默认 true。
	 *
	 * 关掉后该天体仍被所有天体吸引（照常受引力、走接触），但它不再吸引别人 ——
	 * 求解器里标记为「测试粒子」（FCosmosBodyState::bTestParticle），它作为引力源
	 * 的质量按 0 计。
	 *
	 * 典型用途是玩家飞船：飞船不该把行星从轨道上拽动。**接触解算不受影响** ——
	 * 它仍按真实 MassEarth 分配让路，撞地行为与开不开这一项无关。
	 *
	 * 与 MassEarth、InitialVelocityKmPerSecond 一样，**注册时读一次**
	 * （BeginPlay 后首个 Tick）。PIE 中途改这一项要重开 PIE 才生效。
	 */
	UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Cosmos|Body")
	bool bExertsGravity = true;

	/**
	 * 初速度，单位 **km/s（物理速度）**。**天体初速度的唯一来源。**
	 *
	 * 留零即静止，天体只受引力作用。方向与大小都照填，没有任何推导或修正。
	 *
	 * 物理换算：1 AU/年 = 4.7404704635 km/s，地球的 2π AU/年 ≈ 29.79 km/s。
	 * 圆轨道速度先按求解器单位算：v[AU/年] = 2π√(M[M☉]/r[AU])，再乘
	 * 4.7404704635 换成 km/s。M[M☉] = MassEarth × 3.0034893e-6。
	 *
	 * **物理速度 ≠ HUD 上的世界速度**：1 AU/年 = CentimetersPerAu × TimeScale
	 * 厘米/秒（默认 3330 cm/s）。两边都正确，只是两个不同的量 —— 见 spec §3.2。
	 *
	 * **注意**：速度箭头画的是求解器里的**当前**速度，不是这一项 —— 这一项只决定开局。
	 */

		meta = (DisplayName = "初速度（km/s，物理速度）"))
	FVector InitialVelocityKmPerSecond = FVector::ZeroVector;

	// ── 旧字段：只保留序列化与 PostLoad 迁移，代码不再消费 ──
```

- [ ] **Step 4: 改 `CosmosOrbitComponent.cpp`**

整体替换为（保留原有的 `BeginPlay` / `EndPlay` 内容）：

```cpp
// Copyright Voxel Plugin SAS. All Rights Reserved.

#include "CosmosOrbitComponent.h"

#include "CosmosSimulationSubsystem.h"
#include "CosmosTypes.h"
#include "Engine/World.h"

UCosmosOrbitComponent::UCosmosOrbitComponent()
{
	// 物理推进仍归 UCosmosSimulationSubsystem 统一做。本组件开 Tick 只为了刷新
	// 三个只读回显（AU / km/s / M☉）—— 它在 PostPhysics 跑，读到的是本帧写回
	// 之后的最终状态；它不碰求解器、不写物理。
	PrimaryComponentTick.bCanEverTick = true;
	PrimaryComponentTick.bTickInEditor = true;
	PrimaryComponentTick.TickGroup = TG_PostPhysics;
}

void UCosmosOrbitComponent::PostLoad()
{
	Super::PostLoad();

	// 旧字段非零 = 这份数据存于单位变更之前（2026-10-19）。
	// 新字段仍是构造默认值 → 还没迁移过。两者都查，保证重复 PostLoad 幂等。
	if (MassSolar > 0.0)
	{
		if (MassEarth == 1.0)
		{
			MassEarth = CosmosUnits::SolarMassToEarthMass(MassSolar);
		}
		MassSolar = 0.0;
	}

	if (!InitialVelocity.IsZero())
	{
		if (InitialVelocityKmPerSecond.IsZero())
		{
			InitialVelocityKmPerSecond =
				CosmosUnits::AuPerYearToKilometerPerSecond(InitialVelocity);
		}
		InitialVelocity = FVector::ZeroVector;
	}
}

void UCosmosOrbitComponent::TickComponent(float DeltaTime, ELevelTick TickType,
	FActorComponentTickFunction* ThisTickFunction)
{
	Super::TickComponent(DeltaTime, TickType, ThisTickFunction);

	MassSolarReadout = MassEarth * CosmosUnits::EarthMass;
	SolverVelocityKmPerSecond = InitialVelocityKmPerSecond;

	double CmPerAu = 0.0;
	if (const UWorld* World = GetWorld())
	{
		if (const UCosmosSimulationSubsystem* Subsystem =
			World->GetSubsystem<UCosmosSimulationSubsystem>())
		{
			CmPerAu = Subsystem->CentimetersPerAu;

			if (SimulatorIndex != INDEX_NONE)
			{
				SolverVelocityKmPerSecond = CosmosUnits::AuPerYearToKilometerPerSecond(
					Subsystem->GetBodyVelocityGameUnits(SimulatorIndex));
			}
		}
	}

	// 编辑器世界没有 Cosmos 子系统（DoesSupportWorldType 只放 Game/PIE），
	// 退回同一份配置的 CDO —— 不猜标定值。
	if (CmPerAu <= 0.0)
	{
		CmPerAu = GetDefault<UCosmosSimulationSubsystem>()->CentimetersPerAu;
	}

	if (const AActor* Owner = GetOwner())
	{
		if (CmPerAu > 0.0)
		{
			PositionAu = Owner->GetActorLocation() / CmPerAu;
		}
	}
}

void UCosmosOrbitComponent::BeginPlay()
{
	Super::BeginPlay();

	// 组件自己找上门注册，而不是让子系统去遍历全关卡的 Actor：
	// 遍历全世界既慢，又会漏掉运行期生成的 Actor。
	if (const UWorld* OwningWorld = GetWorld())
	{
		if (UCosmosSimulationSubsystem* CosmosSubsystem = OwningWorld->GetSubsystem<UCosmosSimulationSubsystem>())
		{
			CosmosSubsystem->RegisterBody(this);
		}
	}
}

void UCosmosOrbitComponent::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
	if (const UWorld* OwningWorld = GetWorld())
	{
		if (UCosmosSimulationSubsystem* CosmosSubsystem = OwningWorld->GetSubsystem<UCosmosSimulationSubsystem>())
		{
			CosmosSubsystem->UnregisterBody(this);
		}
	}

	Super::EndPlay(EndPlayReason);
}
```
